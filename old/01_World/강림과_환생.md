# 강림과 환생

## 강림

저승의 존재가 현세에 자신의 존재 또는 힘을 구현하는 현상.

강력한 존재일수록 현세의 법칙을 크게 왜곡할 수 있다.

## 환생

저승의 존재가 저승에서 죽으면 현세로 환생한다.

환생 시 기존의 기억은 모두 사라진다.

```text
인간
→ 죽음
→ 저승의 존재
→ 저승에서 죽음
→ 기억 소멸
→ 인간으로 환생
```

## 의미

신 역시 영원한 존재가 아니다.

신도 죽을 수 있으며,
죽은 신은 다시 인간이 된다.

따라서 인간과 신 사이에는 절대적인 종족적 경계가 존재하지 않는다.
