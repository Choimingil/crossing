# 제6장: 안동 하회 — 이름을 남기는 연합

하회 별신굿의 탈들이 판테온·민간조직·귀신 세력 인물의 얼굴을 복제한다. 탈을 오래 쓴 사람은 개인의 이름을 잃고 자신이 속한 진영의 주장만 반복한다.

주인공은 세 진영의 대표를 한자리에 모아 통합 협상을 시작하지만 강경파들은 통합을 상대 진영의 소멸로 이해한다.

## 전투 5회
1. 진영 인물을 복제한 탈귀 식별
2. 서낭당으로 향하는 대표단 호송
3. 협상을 습격한 세 진영 강경파 제압
4. 이름을 빼앗긴 대표들의 기억 회수
5. 모든 얼굴을 삼킨 대탈귀 격파

주인공은 판테온의 법, 민간조직의 계약, 귀신 세력의 존재권을 유지한 연합 헌장 초안을 만든다. 통합 뒤에도 각 진영의 이름과 내부 자치권은 남는다.
