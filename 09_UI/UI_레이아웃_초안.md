# UI 레이아웃 초안

## 참고 방향

상용 SRPG에서 반복적으로 사용하는 다음 원칙을 차용하되 특정 작품의 화면을 그대로 복제하지 않는다.

- 전장을 가장 넓게 보여 주고 명령은 선택 후 노출
- 이동 범위와 공격 범위의 색상 분리
- 공격 확정 전 예상 피해·반격·ST 표시
- 캐릭터 초상화와 핵심 상태를 화면 가장자리에서 유지
- 터치 한 번은 미리보기, 두 번째 확인은 확정

## 가로 전투 화면

| 영역 | 권장 비율 | 내용 |
|---|---:|---|
| 중앙 전장 | 70% | 타일맵, 유닛, 이동·공격·시야 범위 |
| 좌상단 | 15% | 선택 캐릭터 초상화, HP, ST |
| 우상단 | 15% | 라운드, 현재 진영, 메뉴 |
| 오른쪽 패널 | 선택 시 25% | 장착 기술 최대 4개, 영력 기술, 대기 |
| 하단 미리보기 | 60% | 예상 피해, 명중률, 반격 여부, 소모 ST |
| 좌하단 | 20% | 승리·패배 조건, 미니맵 전환 |

오른쪽 패널은 평상시 접어 전장을 가리지 않고 유닛 선택 후 펼친다.

## 색상

| 표시 | 색 |
|---|---|
| 이동 가능 | 청색 |
| 기본 공격 | 적색 |
| 기술 범위 | 주황색 |
| 아군 시야 | 청록 외곽선 |
| 적 위험 범위 | 반투명 자홍 |
| 엄폐물 시야 차단 | 회색 빗금 |
| 선택 확정 | 금색 테두리 |

색상만으로 구분하지 않고 패턴과 아이콘을 함께 사용한다.

## 전투 조작

1. 아군 한 번 탭: 상태와 이동 범위 표시
2. 이동 칸 한 번 탭: 경로 미리보기
3. 같은 칸 다시 탭: 이동 확정
4. 기술 선택: 공격 가능 대상과 범위 표시
5. 대상 탭: 예상 결과 표시
6. 확인 버튼: 행동 실행
7. 행동 후 방향 선택: 무료 확정

이동 확정 이후에는 취소할 수 없으므로 확인 전에 경고색 테두리를 표시한다.

## 예상 결과 패널

- 공격자와 대상 초상화
- 공격 전후 예상 HP
- 명중률
- 공격 소모 ST
- 반격 가능 여부와 반격 소모 ST
- 상태이상과 이동 효과
- 무기 내구력 변화

## 정비 화면

하단 탭을 사용한다.

| 탭 | 기능 |
|---|---|
| 팀 | 출전 편성과 장비 |
| 성장 | 능력치·기술 포인트 배분 |
| 기술 | 습득 기술과 전투 장착 4개 |
| 쇼핑 | 일반 재료 온라인 구매 |
| 대장간 | 제작·강화·수리 |
| 사건 | 다음 임무, 사냥터, 기록 |
| 설정 | 저장 상태, 음량, 접근성 |

## 기술 장착 화면

- 좌측: 습득한 무기 기술 목록
- 중앙: 장착 기술 1~4번 슬롯
- 우측: 영력 각성 기술 별도 영역
- 패시브와 마스터리는 별도 활성 영역
- 현재 주무기로 사용할 수 없는 기술은 회색 처리
- 전투 시작 후에는 변경 불가

## 컷신

- 하단 대화창과 좌우 초상화를 사용한다.
- 이름, 대사, 자동 진행, 로그, 건너뛰기를 제공한다.
- 전투에 영향을 주는 선택지는 확인창을 한 번 더 표시한다.
- 이미 본 컷신은 다시 보기와 건너뛰기가 가능하다.

## 접근성

- 최소 터치 영역 44×44 CSS 픽셀
- UI 배율 조정
- 색약용 패턴
- 진동 끄기
- 텍스트 속도·자동 진행 조정
- 화면 회전 잠금 안내
