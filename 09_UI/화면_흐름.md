# 화면 흐름

## 기본 진행 순서

~~~text
정비
→ 전투 전 컷신
→ 전투
→ 전투 후 컷신
→ 정비
~~~

모든 중심 사건은 이 순서를 기본 단위로 사용한다. 조사 내용이 필요한 사건은 전투 전 컷신 안에 대화와 단서 확인을 포함하거나 별도의 조사 장면으로 확장할 수 있다.

## 1. 정비

판테온 본부를 기준으로 다음 기능을 제공한다.

- 출전 캐릭터 편성
- 능력치 배분
- 기술 습득과 강화
- 무기와 화살통 장착
- 온라인 쇼핑몰에서 재료 구매
- 대장장이 제작·강화·수리
- 사건 정보와 승리 조건 확인
- 저장 상태 확인
- 출전 시작

## 2. 전투 전 컷신

- 사건 장소와 목표를 보여준다.
- 전투가 발생한 원인을 설명한다.
- 출전 인물과 적의 관계를 드러낸다.
- 중요한 기믹과 보호 대상을 자연스럽게 안내한다.
- 컷신 종료 후 초기 배치 확인 화면으로 넘어간다.

## 3. 전투

가로 화면을 기준으로 전장을 넓게 표시하고 선택 유닛의 정보와 행동 버튼을 화면 가장자리에 배치한다.

필수 표시 정보:

- HP, ST
- 이동 가능 범위
- 공격·기술 범위
- 적의 위험 범위
- 예상 피해와 부가 효과
- 현재 라운드와 진영
- 승리·패배 조건
- 바라보는 방향
- 행동 완료 여부

## 4. 전투 후 컷신

- 전투 결과와 사건의 변화를 보여준다.
- 획득한 단서와 인물 관계 변화를 서사에 반영한다.
- 경험치와 돈 등 보상 결과로 연결한다.
- 신규 동료, 쇼핑몰 재료, 제작 기능 등의 해금 여부를 알린다.

## 5. 결과와 정비 복귀

~~~text
전투 결과
→ 경험치와 레벨업
→ 돈 및 특수 재료 획득
→ 해금 항목 표시
→ 판테온 정비 화면 복귀
~~~

레벨업으로 받은 능력치와 기술 포인트는 즉시 배분하지 않아도 보관한다.

## 모바일 가로 UI 원칙

- 터치 조작만으로 모든 기능을 사용할 수 있게 한다.
- 확인과 취소 버튼 위치를 화면 전체에서 일관되게 유지한다.
- 타일 선택은 한 번 탭해 미리 보고 다시 확인해 확정하는 방식을 기본으로 한다.
- 상세 배치는 [[UI_레이아웃_초안]]을 따른다.
- 작은 아이콘만으로 상태를 전달하지 않고 짧은 텍스트 설명을 함께 제공한다.
- 기기 노치와 홈 표시 영역을 제외한 안전 영역 안에 핵심 버튼을 배치한다.
