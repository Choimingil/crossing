# 제작과 강화

## 제작

좋은 금속을 확보하여 좋은 무기를 제작한다.

플레이어는 완성된 무기를 구입하는 것보다
재료를 확보하는 방식으로 성장한다.

## 강화

일반적인 RPG의 +1, +2, +3 방식을 사용하지 않는다.

대신 금속의 열처리를 통해
무기가 가진 잠재력을 최대한 끌어낸다.

## 성장 구조

```text
재료 확보
→
무기 제작
→
열처리 / 가공
→
잠재 성능 해방
```
