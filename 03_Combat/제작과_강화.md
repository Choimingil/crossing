# 제작과 강화

## 담당 조직
무기 제작과 강화는 전투 파티원이 직접 담당하지 않는다. 각 퇴마사가 소속된 종교·판테온 조직이 정규 고용한 기술자들이 담당한다.

주요 인력:
- 금속공학자와 대장장이
- 성물 보존·복원 전문가
- 부적·의식 도구 제작자
- 영력 안전 담당자

이들은 성직자가 아닐 수도 있지만 종교 조직의 보안 규약과 영력 취급 교육을 이수한다. 교단마다 기술과 성물 데이터가 자산이므로 기술자 영입과 보호도 종교 세력 경쟁의 일부다.

## 제작
플레이어는 완성 무기를 단순 구매하기보다 사건과 의뢰에서 금속·성물 조각·전승 기록을 확보한다. 소속 종교의 기술자가 재료 특성과 사용자의 [[자연철학적_성향]]을 분석해 장비를 제작한다.

## 강화
일반적인 +1, +2 방식 대신 열처리·가공·성물 결합·영력 회로 조정을 통해 잠재 성능을 해방한다.

```text
재료 확보 → 조직 기술자에게 의뢰 → 제작·열처리
→ 영력 안전 검사 → 잠재 성능 해방
```
