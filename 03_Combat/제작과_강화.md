# 제작과 강화

## 담당 조직
무기 제작과 강화는 전투 파티원이 직접 담당하지 않는다. 주인공 일행이 소속된 [[판테온]]의 장비 기술팀이 담당한다.

주요 인력:
- 금속공학자와 대장장이
- 성물 보존·복원 전문가
- 부적·의식 도구 제작자
- 영력 안전 담당자

이들은 성직자가 아닐 수도 있지만 판테온의 보안 규약과 영력 취급 교육을 이수한다.

## 제작과 강화
플레이어는 사건에서 금속·성물 조각·전승 기록을 확보한다. 기술팀은 재료와 사용자의 [[자연철학적_성향]]을 분석해 장비를 제작하고 열처리·가공·성물 결합·영력 회로 조정으로 잠재 성능을 해방한다.
