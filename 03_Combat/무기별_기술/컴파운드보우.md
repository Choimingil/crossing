# 컴파운드보우 기술

[[무기별_기술/개요|무기별 기술 개요]]

## 개요
정밀성과 안정성에 특화된 원거리 무기. 모든 공격 기술은 `사격(Shot)` 타입이며 **기본 사거리 2칸**을 공통으로 사용한다.

- 모든 액티브 기술 사거리: 2칸
- 기술 레벨 상승으로 사거리는 증가하지 않는다.
- 사거리는 시전자 기준 맨해튼 거리로 계산한다.
- 장점: 높은 단일 안정성, 정밀 사격, 제압 효과, 이동하지 않았을 때 강한 성능
- 단점: 각궁보다 ST 부담이 크고, 장궁보다 일격 위력과 사거리가 낮다.
