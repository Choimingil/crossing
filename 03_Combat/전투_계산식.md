# 전투 계산식

> 최초 프로토타입용 초안이다. 실제 플레이 테스트 결과에 따라 계수는 조정한다.

## 1. 기본 표기

| 표기 | 의미 |
|---|---|
| HP | 체력 |
| STR | 근력 |
| SPI | 정신력 |
| STA | 지구력 |
| SPD | 민첩성에서 계산한 스피드 |
| ST | 무기 기술 사용 자원 |
| EP | 영력 기술 사용 자원 |
| WP | 무기 기본 위력 |
| 계수 | 기술별 위력 배율 |

## 2. 파생 능력치

| 항목 | 초안 공식 |
|---|---|
| 최대 HP | 100 + 체력 투자치 × 10 |
| 최대 ST | 30 + 지구력 × 3 |
| 최대 EP | 10 + 정신력 × 2 |
| 스피드 | 민첩성 + 장비·상태 보정 |
| 물리 공격력 | 근력 × 2 + 무기 위력 |
| 영력 공격력 | 정신력 × 2 + 영력 출력 |
| 물리 방어력 | 체력 + 지구력 |
| 영력 방어력 | 체력 + 정신력 |

체력은 캐릭터의 기본 생존 능력치로 유지하고, 레벨업 배분 대상인 근력·정신력·지구력·민첩성과 분리한다. 캐릭터별 기본 체력과 성장치는 [[성장_시스템]]에서 관리한다.

## 3. 피해 공식

### 물리 피해

~~~text
기본 피해
= (근력 × 2 + 무기 위력) × 기술 위력 계수

최종 피해
= 기본 피해 × 100 ÷ (100 + 대상 물리 방어력)
~~~

### 영력 피해

~~~text
기본 영력 피해
= (정신력 × 2 + 영력 출력) × 기술 위력 계수

최종 영력 피해
= 기본 영력 피해 × 100 ÷ (100 + 대상 영력 방어력)
~~~

- 계산 마지막에 소수점 이하는 버린다.
- 공격이 적중하면 최소 1의 피해를 준다.
- 범위 공격은 별도 감쇠가 없는 한 모든 대상에게 같은 공식을 적용한다.
- 영력 3단계는 장착 무기의 위력과 강화 수치를 사용하지 않는다.

## 4. 기술 위력 계수 초안

| 기술 역할 | 위력 계수 | 권장 ST | 기준 |
|---|---:|---:|---|
| 기본 공격 | 100% | 0 | 자원 없이 사용하는 기준 공격 |
| 저비용 단일 공격 | 115~125% | 4~6 | 부가 효과가 약함 |
| 일반 단일 공격 | 130~150% | 7~10 | 뻗기 기술의 중심 구간 |
| 고위력 단일 공격 | 160~190% | 12~16 | 조건 또는 높은 비용 필요 |
| 비회전 휘두르기 | 대상당 80~105% | 8~12 | 최대 3방향 공격 |
| 회전 휘두르기 | 대상당 70~90% | 13~18 | 최대 4방향 공격 |
| 제어 기술 | 70~100% | 9~13 | 넘어짐 등 제어 포함 |
| 단일 사격 | 110~150% | 7~12 | 무기 기본 사거리 사용 |
| 범위 사격 | 대상당 70~100% | 11~17 | 여러 대상 공격 |
| 영력 2단계 공격 | 130~180% | EP 4~7 | 성향별 액티브 기술 |
| 영력 3단계 고유기 | 220~300% | 전투당 1회 | 캐릭터 고유 발산 공격 |

### 부가 효과에 따른 위력 차감

| 부가 효과 | 권장 위력 차감 |
|---|---:|
| 능력치 감소 1턴 | -10%p |
| 능력치 감소 2턴 | -15%p |
| 넘어짐 | -20%p |
| 밀치기·당기기 | -10%p |
| 이동 후 추가 이동 | -15%p |
| 방어 일부 무시 | 무시 10%당 -5%p |
| 다중 공격 | 총합 피해가 같은 등급의 단일 기술보다 10% 높지 않게 조정 |

위력과 범위, 제어 효과를 동시에 최고 수준으로 주지 않는다. 강한 부가 효과를 가진 기술은 피해 또는 자원 효율 중 하나를 낮춘다.

## 5. 명중과 회피

~~~text
최종 명중률
= 85
+ (공격자 민첩성 - 대상 민첩성) × 2
+ 예리함 보정
+ 기술·상태 보정
~~~

- 최종 명중률은 30~100%로 제한한다.
- 기술 자체의 개별 명중률은 두지 않고 부가 효과나 상태 보정만 적용한다.
- 후방 공격은 명중률 +15%를 받으며 대상은 반격할 수 없다.
- 측면 공격은 명중률 +5%를 받는다.
- 넘어짐 상태는 기존 규칙대로 민첩성 감소와 반격 불가를 적용한다.
- 영력 회복·버프 기술은 명중 판정을 하지 않는다.

## 6. 치명타

최초 프로토타입에는 치명타를 사용하지 않는다. 명중·회피·방향·기술 범위에 집중하고 필요할 경우 테스트 후 추가한다.

## 7. 반격

- 공격받은 대상이 공격 종료 후 생존하면 반격을 판정한다.
- 공격자를 현재 장착 무기의 기본 공격으로 공격할 수 있는 거리여야 한다.
- 반격은 기본 공격 위력의 80%로 계산한다.
- 유닛 하나당 적군 턴에 1회만 반격한다.
- 범위 공격은 주 대상으로 지정된 유닛만 반격한다.
- 후방에서 공격받았거나 넘어짐 상태라면 반격할 수 없다.
- 원거리 무기는 자신의 사거리에서 공격받았을 때만 반격한다.
- 반격에는 ST와 내구력을 소모하지 않는 가안을 사용하고 프로토타입에서 검증한다.

## 8. ST와 EP

### ST

- 전투 시작 시 최대치로 시작한다.
- 아군 진영 턴 시작 시 최대 ST의 20%를 회복한다.
- 대기를 선택하면 최대 ST의 20%를 추가 회복한다.
- 기본 공격은 ST를 소모하지 않는다.
- ST가 부족하면 해당 무기 기술을 사용할 수 없다.

### EP

- 전투 시작 시 0으로 시작한다.
- 적에게 피해를 주면 1 획득한다. 한 행동에서 여러 명을 공격해도 1만 획득한다.
- 피해를 받으면 1 획득한다. 한 번의 공격당 1만 획득한다.
- 최대 EP를 초과할 수 없다.
- 영력 2단계 액티브 기술 사용 시 기술별 EP를 소모한다.
- 영력 3단계는 전투당 1회 제한을 우선 적용하며 EP 비용은 두지 않는다.

## 9. 버프·디버프·상태이상

- 능력치 증감은 기본적으로 2턴 지속한다.
- 같은 효과는 중첩하지 않고 더 높은 수치와 더 긴 남은 시간을 적용한다.
- 서로 다른 이름의 효과라도 같은 능력치 증감은 합산 최대 ±30%로 제한한다.
- 행동 불가 계열 상태는 기본 1턴이다.
- 보스는 행동 불가 대신 해당 상태의 능력치 감소 효과만 받는다.
- 상태 효과는 대상 진영의 턴 종료 시 지속 턴이 1 감소한다.

## 10. 선공 판정

~~~text
아군팀 총 스피드 = 출전한 모든 아군의 현재 스피드 합
적팀 총 스피드 = 배치된 모든 적의 현재 스피드 합
~~~

- 총 스피드가 높은 팀이 첫 라운드의 선공권을 가진다.
- 동률이면 아군팀이 먼저 행동한다.
- 선공 판정은 전투 시작 시 한 번만 한다.
- 증원과 전투 중 스피드 변화는 이미 정해진 선공권을 바꾸지 않는다.
- 이후에는 선공팀 → 후공팀 순서를 반복한다.

## 11. 레벨 1 기준 밸런스 목표

- 일반 적은 동레벨 기본 공격 4~5회에 처치된다.
- 고위력 단일 기술은 일반 적 최대 HP의 약 30~40% 피해를 목표로 한다.
- 휘두르기로 3명을 공격했을 때 총합 피해는 단일 기술의 약 1.6~2.0배를 넘지 않는다.
- 일반 캐릭터는 동레벨 일반 적의 기본 공격 4회 이상을 버틴다.
- 보스는 권장 출전 인원의 집중 공격으로 6~10라운드 안에 처치되는 것을 목표로 한다.

## 12. 조정 원칙

1. 먼저 기본 공격과 일반 적의 체력을 맞춘다.
2. 단일 기술은 기본 공격 대비 피해와 ST 효율을 맞춘다.
3. 범위 기술은 대상 수가 늘수록 개별 피해를 낮춘다.
4. 제어 기술은 피해보다 행동 이득을 기준으로 평가한다.
5. 영력 기술은 EP 획득 속도와 전투당 평균 사용 횟수로 조정한다.
6. 최종 수치는 [[프롤로그_전투]]의 플레이 테스트 후 확정한다.
