# 기술 시스템

## 기본 원칙

공격 기술 타입은 무기의 세부 공격 방식이 아니라 **공격 모션과 전장 역할**을 기준으로 다음 2가지로 통일한다.

```text
공격 기술
├─ 휘두르기 (Swing)
└─ 뻗기 (Thrust)
```

기존의 `베기 / 찌르기 / 타격 / 걸기 / 사격` 타입은 사용하지 않는다.

타격, 걸기, 사격 등은 필요할 경우 기술 설명이나 부가 효과로 표현한다.

---

# 1. 휘두르기 (Swing)

## 정의

무기나 공격 수단을 넓은 궤적으로 휘둘러 하나 이상의 적을 공격하는 기술 타입.

검의 베기, 철퇴의 타격, 도끼의 내려찍기, 낫의 걸기, 창의 자루 후려치기처럼 동작이 넓은 궤적을 그리는 공격을 포함한다.

## 게임 특성

> **휘두르기 = 낮은 단일 위력 + 범위 공격**

- 뻗기보다 개별 대상에게 주는 위력이 낮다.
- 한 번의 기술로 여러 적을 공격할 수 있다.
- 기술 레벨이 높아질수록 공격 가능한 최대 대상 수가 증가한다.
- 기술 자체의 범위 모양은 유지하고, 그 범위 안에서 공격 가능한 대상 수가 증가하는 방식으로 성장한다.

### 기본 대상 수 성장

일반적인 휘두르기 기술은 다음 성장 곡선을 기준으로 한다.

| 기술 레벨 | 최대 공격 대상 |
|---|---:|
| Lv.1 | 2명 |
| Lv.2 | 2명 |
| Lv.3 | 3명 |
| Lv.4 | 3명 |
| Lv.5 | 4명 |

대회전처럼 원래부터 광범위한 기술은 `3 → 3 → 4 → 4 → 5명`처럼 더 높은 값을 사용할 수 있다.

---

# 2. 뻗기 (Thrust)

## 정의

무기 끝, 투사체, 직선적인 공격 동작을 한 대상에게 집중하는 기술 타입.

검·레이피어·창의 찌르기뿐 아니라 활의 사격처럼 한 목표를 향해 직선적으로 힘을 전달하는 공격도 뻗기로 분류한다.

## 게임 특성

> **뻗기 = 높은 위력 + 단일 공격**

- 휘두르기보다 기본 위력이 높다.
- 공격 대상은 기술 레벨과 관계없이 항상 1명이다.
- 레벨 상승 시 대상 수가 아니라 위력, 사거리, 방어 무시 등 기술 고유 성능이 강화된다.

```text
뻗기
→ 최대 공격 대상 1명 고정
→ 기술 레벨 상승 시 단일 대상 성능 강화
```

---

# 3. 타입 비교

| 타입 | 영문 | 위력 성향 | 공격 대상 | 레벨 상승 핵심 |
|---|---|---|---|---|
| 휘두르기 | Swing | 낮음 | 복수 | 위력 + 최대 대상 수 증가 |
| 뻗기 | Thrust | 높음 | 1명 | 위력 + 기술 고유 성능 증가 |

이 구분을 통해 플레이어는 한 기술의 단순 대미지뿐 아니라 **다수 처리와 단일 집중 공격** 중 어떤 역할이 필요한지 판단하게 된다.

---

# 4. 기술 정보

모든 액티브 기술은 기본적으로 다음 정보를 가진다.

```text
기술명
기술 타입
기술 위력 또는 효과
소모 지구력(ST)
사거리
최대 공격 대상 수
부가 효과
```

**기술 자체의 명중률 수치는 사용하지 않는다.**

명중 판정이 필요한 경우 캐릭터 능력치, 무기 숙련도, 상태, 지형 등 별도의 전투 규칙에서 처리한다.

---

# 5. 기술 레벨

각 기술은 `Lv.1 ~ Lv.5`까지 강화할 수 있다.

기술 레벨 상승 시 기존 기술의 성능이 점진적으로 상승하며, 특정 레벨에 완전히 새로운 기능을 별도로 해금하는 구조는 기본적으로 사용하지 않는다.

## 액티브 기술

```text
기술 레벨 상승
→ 위력 또는 기존 효과 상승
→ 소모 ST 상승
```

### 휘두르기

```text
기술 레벨 상승
→ 위력 상승
→ 최대 공격 대상 수 증가
→ ST 상승
```

### 뻗기

```text
기술 레벨 상승
→ 단일 대상 위력 상승
→ 사거리 / 방어 무시 / 이동 등 기존 효과 강화 가능
→ 최대 공격 대상 1명 유지
→ ST 상승
```

# 6. 무기와 기술 타입

하나의 무기는 휘두르기와 뻗기를 모두 사용할 수 있다.

무기 특성에 따라 어느 쪽의 비중이 높은지가 달라진다.

| 무기 | 휘두르기 | 뻗기 | 전투 성향 |
|---|:---:|:---:|---|
| 롱소드 | ● | ● | 균형 |
| 검 | ● | △ | 휘두르기 중심 |
| 레이피어 | △ | ● | 뻗기 중심 |
| 철퇴 | ● | - | 휘두르기 / 방어 파괴 |
| 도끼 | ● | - | 휘두르기 / 고위력 범위 |
| 낫 | ● | - | 휘두르기 / 제어 |
| 창 | △ | ● | 뻗기 / 리치 |
| 월도 | ● | △ | 휘두르기 / 광범위 |
| 폴암 | ● | ● | 상황 대응 |
| 각궁 | - | ● | 기동 단일 사격 |
| 컴파운드보우 | - | ● | 정밀 단일 사격 |
| 장궁 | - | ● | 장거리 단일 고위력 |

- `●`: 주력
- `△`: 일부 기술에서 사용
- `-`: 기본적으로 사용하지 않음

---

# 7. 지구력

기술에는 별도의 사용 횟수를 두지 않고 [[능력치]]의 지구력을 사용한다.

기술이 강해질수록 더 많은 ST를 소비한다.

```text
낮은 기술 레벨
→ 낮은 성능
→ 낮은 ST
→ 반복 사용에 유리

높은 기술 레벨
→ 높은 성능
→ 높은 ST
→ 순간 효율에 유리
```

---

# 8. 마스터리

마스터리는 기술 타입별이 아니라 **무기별 마스터리**로 사용한다.

기본 효과:

- 해당 무기의 숙련도 증가
- 해당 무기로 사용하는 기술의 전반적인 성능 소폭 증가

기술 명중률 증가 효과는 사용하지 않는다.

---

# 핵심 정리

```text
휘두르기 (Swing)
= 낮은 위력
= 범위 공격
= 레벨 상승 시 최대 공격 대상 수 증가

뻗기 (Thrust)
= 높은 위력
= 단일 공격
= 최대 공격 대상 1명 고정

기술 명중률
= 기술 데이터에서 제거

기술 레벨 상승
= 성능 상승 + ST 소모 상승
```
