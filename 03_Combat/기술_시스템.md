# 기술 시스템

## 기본 원칙

공격 기술 타입은 근거리와 원거리 무기의 운용 방식에 따라 다음과 같이 구분한다.

```text
근거리 기술
├─ 휘두르기 (Swing)
└─ 뻗기 (Thrust)

원거리 기술
└─ 사격 (Shot)
```

---

# 1. 근거리 기본 사거리

모든 근거리 액티브 기술의 사거리는 **1칸으로 고정**한다.

사거리 1은 시전자 기준 상·하·좌·우 인접 4칸이며 대각선은 제외한다.

```text
  ■
■ ● ■
  ■
```

레이피어·창처럼 실제 리치가 긴 무기의 장점은 액티브 사거리 증가가 아니라 `관통` 같은 패시브로 표현한다.

---

# 2. 휘두르기 (Swing)

> **휘두르기 = 낮은 개별 위력 + 인접 방향 범위 공격**

휘두르기의 공격 판정은 시전자 기준 `전방 / 좌측 / 우측 / 후방` 4개 인접 방향 안에서 정한다.

## 비회전 휘두르기

일반 베기, 횡베기, 내려치기처럼 시전자가 몸을 완전히 회전하지 않는 기술은 **후방을 공격할 수 없다.**

따라서 일반 비회전 휘두르기의 최대 범위는 다음과 같다.

```text
전방 + 좌측 + 우측
```

레벨이 올라가도 후방은 추가하지 않는다.

## 걸기형 단일 제어 예외

도끼의 `찍어당기기`, 낫의 `걸어당기기`, 폴암의 `갈고리 당기기`처럼 갈고리·날로 한 대상을 거는 기술은 공격 동작이 휘두르기 형태여도 **사거리 1의 단일 대상 제어 기술**로 처리한다.

```text
걸기형 단일 제어
= 타입: 휘두르기 (Swing)
= 사거리: 1
= 대상: 인접 적 1명
= 효과: 넘어짐
```

### 넘어짐

무기로 상대를 걸어 균형을 무너뜨린 상태다.

- 지속: 1턴
- 효과: 민첩성 감소 + 반격 불가
- 반격 불가는 모든 기술 레벨에서 1턴 고정
- 민첩성 감소량은 기술 레벨에 따라 증가
- 대상의 위치는 변경하지 않는다.

| Lv | 민첩성 감소 | 반격 불가 |
|---|---:|---|
| 1 | -10% | 1턴 |
| 2 | -12% | 1턴 |
| 3 | -14% | 1턴 |
| 4 | -17% | 1턴 |
| 5 | -20% | 1턴 |

적의 회피 성능을 낮추는 기술 효과가 필요한 경우 **직접 회피율 감소를 사용하지 않고 민첩성 감소로 통일**한다.

## 회전 휘두르기

`회전베기`, `대회전`, `회전타격`, `회전수확`처럼 **몸과 무기를 한 바퀴 돌리는 동작이 명확한 기술만 후방을 공격할 수 있다.**

```text
회전 기술 성장 예
Lv.1~2 → 전방 + 좌측 + 우측
Lv.3~5 → 전방 + 좌측 + 우측 + 후방
```

회전 기술은 후방까지 공격할 수 있는 대신 일반 휘두르기보다 높은 ST 소모를 가질 수 있다.

## 휘두르기형 무기 구성 원칙

휘두르기를 주력으로 사용하는 무기는 최소 하나의 회전 공격 기술을 갖는다.

회전 기술이 없다면 **기본 기술은 유지**하고, 나머지 액티브 기술 중 역할이 가장 단순하거나 다른 기술과 겹치는 기술을 회전 기술로 교체한다.

# 3. 뻗기 (Thrust)

> **뻗기 = 높은 위력 + 사거리 1의 직선 단일 공격**

- 정면 인접 1칸의 단일 적을 공격한다.
- 모든 뻗기 액티브 기술의 직접 사거리는 1칸이다.
- 대각선 적은 공격할 수 없다.
- 기술 레벨 상승 시 위력, 방어 무시, 연속 공격 등 기존 단일 대상 성능을 강화한다.

## 관통 패시브

레이피어·창처럼 리치가 긴 무기는 패시브 `관통`으로 특성을 표현한다.

```text
● → A → B
```

뻗기 기술이 A에 적중하면 일정 확률로 A의 직선 뒤 1칸에 있는 B에게 원 피해의 일정 비율만큼 추가 피해를 준다. 대각선에는 발동하지 않으며 관통 피해가 다시 관통을 일으키지 않는다.

---

# 4. 사격 (Shot)

활 등 원거리 무기의 모든 공격 기술은 `사격` 타입으로 통일한다.

## 원거리 기본 사거리

원거리 액티브 기술은 **기술마다 사거리가 달라지지 않고, 장착한 무기의 기본 사거리**를 사용한다.

| 무기 | 기본 사거리 | 운용 특성 |
|---|---:|---|
| 각궁 | 2칸 | 기동성 / 빠른 사격 |
| 컴파운드보우 | 2칸 | 안정적인 정밀 사격 / 제압 |
| 장궁 | 3칸 | 최장거리 / 고위력 / 관통 |

- 같은 무기에서 사용하는 모든 액티브 사격 기술은 기본적으로 동일한 사거리를 사용한다.
- 기술 레벨 상승으로 사거리가 증가하지 않는다.
- 기술의 개성은 위력, ST, 공격 범위 형태, 방어 무시, 이동 등으로 구분한다.
- 원거리 사거리는 시전자 기준 상·하·좌·우 이동 거리와 동일한 **맨해튼 거리**로 계산한다.
- 범위기가 아닌 단일 사격은 선택한 공격 방향의 기본 사거리 안에서 **시전자와 가장 가까운 적 하나만** 지정할 수 있다. 더 가까운 적을 건너뛰어 뒤의 적을 지정할 수 없다.
- 범위 사격은 기본 사거리 안의 기준 칸 또는 방향을 지정한 뒤 기술에 정의된 범위에 피해를 준다.

## 사격 범위

사격은 기술별로 단일 또는 범위 공격이 될 수 있다.

```text
단일 사격
→ 기본 사거리 안에서 적 1명 지정

직선 사격
→ 기본 사거리 안에서 지정한 방향의 직선 칸 공격

지정 범위 사격
→ 기본 사거리 안의 한 칸을 중심점으로 지정
→ 중심점 주변의 기술 범위 공격

확산 / 제압 사격
→ 기본 사거리 안에서 방향 지정
→ 해당 방향의 기술별 범위 공격
```

범위 안에 포함된 적은 모두 피격되며 별도의 최대 피격 인원 수는 두지 않는다.

---

# 5. 기술 정보

모든 액티브 기술은 다음 정보를 가진다.

```text
기술명
기술 타입
기술 위력 또는 효과
소모 지구력(ST)
사거리
공격 범위
부가 효과
```

기술별 명중률과 최대 공격 대상 수는 사용하지 않는다. 실제 피격 대상 수는 공격 판정 칸에 포함된 적의 수로 결정한다.

---

# 6. 기술 레벨

각 기술은 `Lv.1 ~ Lv.5`까지 강화한다.

```text
기술 레벨 상승
→ 기존 성능 상승
→ ST 소모 상승
```

- 비회전 휘두르기: 전방·좌측·우측 안에서만 범위 확대
- 걸기형 단일 제어: 단일 대상 유지, 위력·민첩성 감소 강화
- 회전 휘두르기: 일정 레벨부터 후방 포함 가능
- 뻗기: 사거리 1을 유지하며 단일 성능 강화
- 사격: **무기 기본 사거리는 유지**하며 위력·범위 형태·부가 효과 강화

# 8. 지구력

기술에는 별도의 사용 횟수를 두지 않고 [[능력치]]의 지구력을 사용한다. 기술이 강해질수록 더 많은 ST를 소비한다.

---

# 9. 마스터리

마스터리는 기술 타입별이 아니라 **무기별 마스터리**로 사용한다.

- 해당 무기의 숙련도 증가
- 해당 무기로 사용하는 기술의 전반적인 성능 소폭 증가

# 핵심 정리

```text
근거리 액티브 기술
= 전부 사거리 1

비회전 휘두르기
= 전방 / 좌측 / 우측까지만
= 후방 공격 불가

걸기형 단일 제어
= 휘두르기 타입 유지
= 단일 대상
= 넘어짐 부여
= 1턴 민첩성 감소 + 반격 불가

회전 휘두르기
= 후방 공격 가능

뻗기
= 사거리 1 단일 공격
= 긴 리치는 관통 패시브로 표현

원거리 사격
= 무기별 기본 사거리 고정
각궁 2 / 컴파운드보우 2 / 장궁 3
= 기술 레벨로 사거리 증가 없음
= 기술별 단일 / 범위 형태로 차별화
```
