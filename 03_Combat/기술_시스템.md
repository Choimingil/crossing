# 기술 시스템

## 기본 원칙

공격 기술 타입은 근거리와 원거리 무기의 운용 방식에 따라 다음과 같이 구분한다.

```text
근거리 기술
├─ 휘두르기 (Swing)
└─ 뻗기 (Thrust)

원거리 기술
└─ 사격 (Shot)
```

---

# 1. 휘두르기 (Swing)

근거리 무기를 넓은 궤적으로 휘둘러 여러 칸을 공격하는 기술이다.

> **휘두르기 = 낮은 개별 위력 + 방향 기반 범위 공격**

근거리 휘두르기 기술의 공격 범위는 기본적으로 **시전자 주변 1칸**에서 정한다.

공격 대상 수를 별도의 숫자로 제한하지 않는다. 실제 피격 대상은 기술이 지정한 방향과 범위 칸 안에 존재하는 모든 적이다.

예시 범위:

```text
전방 3칸
■ ■ ■
  ●

좌우 3칸
■ ● ■
  ■

전방 부채꼴 3칸
■ ■ ■
  ●

주변 8칸
■ ■ ■
■ ● ■
■ ■ ■
```

`●`는 시전자, `■`는 공격 판정 칸을 의미한다.

기술 레벨 상승 시 **기존 범위의 방향성은 유지하면서 공격 판정 칸이 점진적으로 확대**될 수 있다.

예:

```text
횡베기
Lv.1 → 정면 + 좌측
Lv.2 → 정면 + 좌측 + 우측
Lv.3~5 → 같은 방향 구조를 유지하며 대각선 또는 후방 인접 칸까지 확장 가능
```

단, 모든 휘두르기 기술이 주변 8칸 전체를 공격하는 것은 아니다. 기술의 실제 동작에 맞게 전방, 좌우, 부채꼴, 회전 등으로 범위를 정한다.

---

# 2. 뻗기 (Thrust)

근거리 무기의 끝이나 직선 동작을 한 목표에 집중하는 기술이다.

> **뻗기 = 높은 위력 + 단일 공격**

- 공격 대상은 기본적으로 1명이다.
- 근거리 기술은 시전자 주변 1칸 또는 무기의 리치가 허용하는 직선 칸을 대상으로 한다.
- 기술 레벨 상승 시 대상 수가 아니라 위력, 사거리, 방어 무시, 이동 등 기술 고유 성능이 강화된다.

---

# 3. 사격 (Shot)

활 등 원거리 무기의 모든 공격 기술은 `사격` 타입으로 통일한다.

사격은 기술에 따라 단일 공격과 범위 공격을 모두 사용할 수 있다.

예:

- 사격 / 조준사격 / 저격 → 단일 대상
- 연사 → 동일 대상 또는 직선상의 복수 대상
- 곡사 → 지정 지점 주변 범위
- 제압사격 → 지정 방향 또는 지정 구역 범위

사격 기술은 근거리의 `휘두르기 / 뻗기` 분류를 사용하지 않는다.

## 원거리 범위 판정

원거리 범위 기술은 다음 두 요소를 기술별로 정의한다.

1. **사거리**: 시전자에서 공격 지점까지의 거리
2. **범위 형태**: 선택 지점 또는 방향을 기준으로 실제 피해를 주는 칸

예:

```text
곡사
사거리: 4
범위: 지정 지점 주변 1칸

제압사격
사거리: 3
범위: 지정 방향 직선 3칸
```

따라서 원거리 기술 역시 `최대 공격 대상 수`를 별도로 두지 않고, 범위 안에 존재하는 적이 모두 피격된다.

---

# 4. 기술 정보

모든 액티브 기술은 기본적으로 다음 정보를 가진다.

```text
기술명
기술 타입
기술 위력 또는 효과
소모 지구력(ST)
사거리
공격 범위
부가 효과
```

`최대 공격 대상 수` 항목은 사용하지 않는다.

실제 피격 대상 수는 **공격 범위에 포함된 적의 수**로 결정한다.

기술 자체의 명중률 수치도 사용하지 않는다.

---

# 5. 기술 레벨

각 기술은 `Lv.1 ~ Lv.5`까지 강화할 수 있다.

기술 레벨 상승 시 기존 기술의 성능이 점진적으로 상승하며, 액티브 기술은 성능 상승과 함께 ST 소모도 증가한다.

### 휘두르기

```text
기술 레벨 상승
→ 위력 상승
→ 공격 범위 칸 확대 가능
→ ST 상승
```

### 뻗기

```text
기술 레벨 상승
→ 단일 대상 위력 상승
→ 사거리 / 방어 무시 / 이동 등 기존 효과 강화 가능
→ ST 상승
```

### 사격

```text
기술 레벨 상승
→ 위력 상승
→ 단일 기술은 단일 성능 강화
→ 범위 기술은 기존 범위 형태를 유지하며 범위 확대 가능
→ ST 상승
```

# 7. 지구력

기술에는 별도의 사용 횟수를 두지 않고 [[능력치]]의 지구력을 사용한다.

기술이 강해질수록 더 많은 ST를 소비한다.

---

# 8. 마스터리

마스터리는 기술 타입별이 아니라 **무기별 마스터리**로 사용한다.

기본 효과:

- 해당 무기의 숙련도 증가
- 해당 무기로 사용하는 기술의 전반적인 성능 소폭 증가

---

# 핵심 정리

```text
근거리
휘두르기 (Swing)
= 시전자 주변 1칸 기준 방향형 범위 공격
= 범위 내 모든 적 피격

뻗기 (Thrust)
= 높은 위력
= 단일 공격

원거리
사격 (Shot)
= 단일 / 범위 모두 가능
= 기술별 사거리 + 범위 형태로 판정

피격 대상 수
= 별도 수치 없음
= 공격 범위 안의 적 수로 결정
```
