# 기술 시스템

## 기본 원칙

공격 기술은 실제 무기술에서 나타나는 공격 방식을 기반으로 다음 5가지 타입으로 분류한다.

```text
공격 기술
├─ 베기
├─ 찌르기
├─ 타격
├─ 걸기
└─ 사격
```

각 타입은 공격의 물리적인 방식과 전술적 특성을 나타내며, 기술 타입 자체가 위력이나 명중률을 결정하지 않는다.

기술의 실제 성능은 각각의 기술에 설정된 다음 수치로 결정한다.

- 기술 위력
- 기술 명중률
- 소모 지구력
- 사거리
- 공격 범위
- 부가 효과

같은 타입의 기술이라도 서로 다른 성능을 가질 수 있다.

복수 타입 기술은 새로운 타입을 추가하는 것이 아니라 하나의 기술 안에서 둘 이상의 기존 타입을 순차적으로 사용하는 방식이다.

예:

```text
폴암 복합 연계
찌르기 → 베기
타입: 찌르기 + 베기
```

---

# 1. 베기

## 정의

무기의 날을 목표물에 정렬한 상태로 휘둘러 날이 목표물을 지나가도록 공격하는 방식.

대표적인 실제 공격 방식은 Cut / Slash 계열이다.

## 대표 무기

- 롱소드
- 검
- 도끼
- 낫
- 월도
- 일부 폴암

## 실제 무기술의 특징

베기는 무기의 회전과 가속을 이용하여 날을 목표물에 통과시키는 공격이다.

효율적인 베기를 위해서는 다음 요소가 중요하다.

- 무기의 가속
- 공격 궤적
- 날 정렬
- 회전력
- 공격 후 무기의 진행 방향

## 게임 특성

> **베기 = 궤적**

일부 베기 기술은 다음과 같은 특성을 가질 수 있다.

- 전방 복수 타일 공격
- 좌우 범위 공격
- 부채꼴 공격
- 이동하면서 공격
- 여러 적을 연속으로 공격

단, 모든 베기 기술이 범위 공격인 것은 아니다.

---

# 2. 찌르기

## 정의

무기의 끝부분을 상대에게 향하게 한 뒤 직선적인 움직임으로 목표물을 공격하는 방식.

대표적인 실제 공격 방식은 Thrust 계열이다.

## 대표 무기

- 롱소드
- 검
- 레이피어
- 창
- 월도
- 폴암

## 실제 무기술의 특징

찌르기는 무기의 끝과 리치를 이용하여 상대에게 직선적으로 공격하는 방식이다.

주요 특징:

- 직선적인 공격 경로
- 무기 끝부분 활용
- 무기의 길이를 이용한 거리 확보
- 좁은 공격선

## 게임 특성

> **찌르기 = 리치와 직선성**

일부 찌르기 기술은 기본 공격보다 사거리가 증가하거나 여러 칸을 직선으로 관통할 수 있다.

---

# 3. 타격

## 정의

무기의 질량과 운동량을 이용하여 상대에게 강한 충격을 전달하는 공격 방식.

대표적인 실제 공격 방식은 Strike / Blow 계열이다.

## 대표 무기

- 철퇴
- 망치
- 곤봉
- 봉
- 일부 도끼
- 일부 창
- 일부 폴암

## 게임 특성

> **타격 = 충격**

타격 타입은 상대의 방어를 무너뜨리는 기술에 적합하다.

- 방어 효과 일부 무시
- 방패 방어 효과 감소
- 방어 상태 해제
- 자세 붕괴
- 일시적인 방어력 감소

타격의 정체성을 단순히 높은 피해량으로 만들기보다는 **방어에 대한 강점**으로 표현한다.

---

# 4. 걸기

## 정의

무기의 돌출된 부분이나 날의 형태를 이용하여 상대의 신체, 무기 또는 방패를 걸어 제어하는 공격 방식.

Hooking / Tripping / Control 계열의 여러 무기술을 게임 시스템상 하나의 타입으로 통합한 것이다.

## 대표 무기

- 낫
- 도끼
- 할버드
- 폴암
- 일부 월도
- 갈고리 구조가 존재하는 장병기

## 게임 특성

> **걸기 = 물리적 제어**

대표 효과:

- 1칸 당기기
- 밀기
- 넘어뜨리기
- 이동력 감소
- 방향 변경
- 방패 해제
- 자세 붕괴

걸기는 [[수호신]]의 악귀 계열 마법이 사용하는 초자연적인 전장 조작과 구분한다.

```text
걸기
= 물리적인 전장 조작

악귀 마법
= 초자연적인 전장 조작
```

---

# 5. 사격

## 정의

활 등의 원거리 무기를 이용하여 투사체를 발사하는 공격 방식.

## 대표 무기

- 각궁
- 장궁
- 컴파운드보우

## 게임 특성

> **사격 = 거리와 사선**

사격은 원거리에서 적을 공격할 수 있지만 공격 방향의 가장 가까운 상대만 공격할 수 있다.

앞의 적이나 장애물은 뒤의 적에 대한 사선을 차단할 수 있다.

따라서 원거리 캐릭터는 거리뿐 아니라 좋은 사선을 확보하는 것이 중요하다.

---

# 6. 기술 타입 요약

| 타입 | 핵심 | 게임 특성 |
|---|---|---|
| 베기 | 궤적 | 넓은 공격 궤적을 활용하는 기술 |
| 찌르기 | 리치 | 직선 방향과 무기 길이를 활용하는 기술 |
| 타격 | 충격 | 상대의 방어 효과를 무너뜨리는 기술 |
| 걸기 | 제어 | 상대의 위치·자세를 물리적으로 조작 |
| 사격 | 사선 | 원거리 공격 및 사선 관리 |

기술 타입은 **기술이 어떻게 공격하는가**를 나타내며 기술의 강함 자체를 나타내지는 않는다.

---

# 7. 기술 성능

각 기술은 기본적으로 다음 정보를 가진다.

```text
기술명
기술 타입
기술 위력 또는 효과
기술 명중률
소모 지구력
사거리
공격 범위
부가 효과
```

같은 타입이라도 기술에 따라 성능은 달라질 수 있다.

---

# 8. 같은 타입 내 기술 차이

기술 타입에 위력과 명중률을 고정하지 않는다.

예를 들어 모든 찌르기가 `저위력 / 고명중`일 필요는 없다.

```text
견제 찌르기
위력: 80%
명중률: 105%
소모 지구력: 8

기본 찌르기
위력: 100%
명중률: 100%
소모 지구력: 10

돌진 찌르기
위력: 160%
명중률: 80%
소모 지구력: 25
```

즉, **타입은 공격 방법을 결정하고 기술은 성능을 결정한다.**

---

# 9. 무기와 기술 타입

하나의 무기는 하나의 기술 타입에만 제한되지 않는다.

무기의 실제 구조와 사용법에 따라 여러 타입의 기술을 사용할 수 있다.

| 무기 | 베기 | 찌르기 | 타격 | 걸기 | 사격 |
|---|:---:|:---:|:---:|:---:|:---:|
| 롱소드 | ● | ● | △ | - | - |
| 검 | ● | ● | - | - | - |
| 레이피어 | △ | ● | - | - | - |
| 철퇴 | - | - | ● | - | - |
| 도끼 | ● | - | △ | ● | - |
| 낫 | ● | △ | - | ● | - |
| 창 | - | ● | △ | - | - |
| 월도 | ● | ● | - | △ | - |
| 폴암 | ● | ● | ● | ● | - |
| 각궁 | - | - | - | - | ● |
| 컴파운드보우 | - | - | - | - | ● |
| 장궁 | - | - | - | - | ● |

- `●` : 주력 기술 타입
- `△` : 일부 기술에서 사용
- `-` : 기본적으로 사용하지 않음

복수 타입 기술은 표에 존재하는 기존 타입을 조합한다. 별도의 `복합` 타입은 사용하지 않는다.

---

# 10. 무기 카테고리와 기술

같은 무기 카테고리는 기본적인 기술 체계를 공유할 수 있다.

단, 하위 무기의 실제 구조에 따라 사용할 수 있는 기술 타입과 기술 효과가 달라질 수 있다.

```text
도검류

롱소드
→ 베기 + 찌르기

검
→ 베기 중심 + 찌르기

레이피어
→ 찌르기 중심 + 일부 베기
```

---

# 11. 개별 무기의 특화

개별 무기는 특정 기술 또는 기술 타입에 보정을 가질 수 있다.

```text
검
→ 베기 중심

레이피어
→ 찌르기 중심

철퇴
→ 타격 및 방어 파괴 중심

낫
→ 걸기와 물리적 제어 중심

창
→ 찌르기와 리치 중심
```

이를 통해 같은 무기 카테고리 안에서도 하위 무기마다 플레이 스타일이 달라진다.

---

# 12. 지구력

기술에는 별도의 사용 횟수를 두지 않는다.

대신 [[능력치]]의 지구력을 사용한다.

```text
기술 사용
→ 지구력 감소
```

강력하거나 복잡한 기술일수록 일반적으로 더 많은 지구력을 소비한다.

## 지구력 회복

- 무행동
- 회복 행동
- 일부 기술 또는 마법

## 지구력 부족

지구력이 낮아지면 공격 효율이 감소한다.

플레이어는 강력한 기술의 연속 사용과 지구력 관리 사이에서 선택해야 한다.

---

# 13. 반격

반격 역시 기술 사용과 마찬가지로 지구력을 소비한다.

반격 가능 여부는 다음 요소의 영향을 받는다.

- 공격 거리
- 자신의 무기 리치
- 상대 무기 리치
- 무기 종류
- 현재 지구력
- 상태 이상

근거리 전투에서 상대의 무기 리치가 자신의 무기 리치보다 길 경우 상황에 따라 반격이 제한될 수 있다.

원거리 무기는 기본적으로 근거리 반격을 할 수 없다.

---

# 14. 리치와 이동력

무기의 리치가 길수록 전투 거리에서 유리하다.

대신 긴 무기는 캐릭터의 이동력에 더 큰 부담을 줄 수 있다.

```text
긴 무기
→ 높은 리치
→ 이동력 감소량 증가

짧은 무기
→ 낮은 리치
→ 이동력 감소량 감소
```

따라서 무기 선택은 위력, 기술, 리치, 이동력, 반격 능력을 함께 고려하는 선택이 된다.

---

# 15. 마스터리

마스터리는 **기술 타입별 숙련이 아니라 무기별 마스터리**로 통일한다.

각 주무기는 자신의 이름을 가진 마스터리를 하나씩 가진다.

```text
롱소드 → 롱소드 마스터리
검 → 검 마스터리
레이피어 → 레이피어 마스터리
철퇴 → 철퇴 마스터리
도끼 → 도끼 마스터리
낫 → 낫 마스터리
창 → 창 마스터리
월도 → 월도 마스터리
폴암 → 폴암 마스터리
각궁 → 각궁 마스터리
컴파운드보우 → 컴파운드보우 마스터리
장궁 → 장궁 마스터리
```

모든 무기 마스터리의 기본 효과는 다음 두 가지로 통일한다.

- **해당 무기의 숙련도 증가**
- **해당 무기로 사용하는 모든 기술의 명중률 증가**

예:

```text
철퇴 마스터리
→ 철퇴 숙련도 증가
→ 철퇴 기술 명중률 증가

폴암 마스터리
→ 폴암 숙련도 증가
→ 폴암의 베기 / 찌르기 / 타격 / 걸기 기술 명중률 증가
```

마스터리는 기술 포인트를 투자하여 강화할 수 있으며, 레벨이 오를수록 숙련도와 기술 명중률 보너스가 함께 증가한다.

구체적인 성장 수치는 [[무기별_기술]]에서 정의한다.

---

# 16. 기술 설계 원칙

새로운 기술을 만들 때 다음 순서로 설계한다.

```text
1. 실제 무기 동작 결정
↓
2. 기술 타입 결정
↓
3. 기술의 전술적 목적 결정
↓
4. 위력 결정
↓
5. 명중률 결정
↓
6. 소모 지구력 결정
↓
7. 사거리 / 범위 결정
↓
8. 부가 효과 결정
```

복수 타입 기술의 경우 2단계에서 사용되는 기존 타입들을 순서대로 함께 표기한다.

# 핵심 정리

본 게임에서 공격 기술은 다음 5가지 타입을 사용한다.

```text
베기 = 궤적
찌르기 = 리치와 직선성
타격 = 충격
걸기 = 물리적 제어
사격 = 거리와 사선
```

```text
기술 타입
→ 공격 방식과 전술적 성질

기술 위력
→ 개별 기술에서 결정

기술 명중률
→ 개별 기술에서 결정

소모 지구력
→ 개별 기술에서 결정

마스터리
→ 무기별 숙련도 + 해당 무기 기술 명중률 증가
```

이를 통해 실제 무기술의 다양성을 유지하면서 SRPG에서 각 기술과 무기의 전술적 차이를 명확하게 만든다.
