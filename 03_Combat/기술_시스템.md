# 기술 시스템

## 기본 원칙

공격 기술은 실제 무기술에서 나타나는 공격 방식을 기반으로 다음 5가지 타입으로 분류한다.

```text
공격 기술
├─ 베기
├─ 찌르기
├─ 타격
├─ 걸기
└─ 사격
```

이 분류는 역사적으로 존재했던 하나의 통일된 무기술 분류 체계를 그대로 사용하는 것이 아니라,
여러 무기술에서 나타나는 실제 공격 방식을 게임 시스템에 맞게 통합한 것이다.

각 타입은 공격의 물리적인 방식과 전술적 특성을 나타낸다.

**기술 타입 자체가 위력이나 명중률을 결정하지 않는다.**

기술의 실제 성능은 각각의 기술에 설정된 다음 수치로 결정한다.

- 기술 위력
- 기술 명중률
- 소모 지구력
- 사거리
- 공격 범위
- 부가 효과

따라서 같은 타입의 기술이라도 서로 다른 성능을 가질 수 있다.

---

# 1. 베기

## 정의

무기의 날을 목표물에 정렬한 상태로 휘둘러
날이 목표물을 지나가도록 공격하는 방식.

대표적인 실제 공격 방식은 Cut / Slash 계열이다.

## 대표 무기

- 롱소드
- 검
- 도끼
- 낫
- 월도
- 일부 폴암

## 실제 무기술의 특징

베기는 무기의 회전과 가속을 이용하여 날을 목표물에 통과시키는 공격이다.

효율적인 베기를 위해서는 다음 요소가 중요하다.

- 무기의 가속
- 공격 궤적
- 날 정렬
- 회전력
- 공격 후 무기의 진행 방향

찌르기에 비해 공격 궤적을 넓게 활용할 수 있다는 것이 특징이다.

## 게임 특성

> **베기 = 궤적**

베기 타입 기술은 공격 궤적을 이용하는 기술에 적합하다.

따라서 일부 베기 기술은 다음과 같은 특성을 가질 수 있다.

- 전방 복수 타일 공격
- 좌우 범위 공격
- 부채꼴 공격
- 이동하면서 공격
- 여러 적을 연속으로 공격

예:

```text
횡베기

  ■■■
   👤
```

단, 모든 베기 기술이 범위 공격인 것은 아니다.

기본 베기나 빠른 베기처럼 단일 대상을 공격하는 기술도 존재할 수 있다.

---

# 2. 찌르기

## 정의

무기의 끝부분을 상대에게 향하게 한 뒤
직선적인 움직임으로 목표물을 공격하는 방식.

대표적인 실제 공격 방식은 Thrust 계열이다.

## 대표 무기

- 롱소드
- 검
- 레이피어
- 창
- 월도
- 폴암

## 실제 무기술의 특징

찌르기는 무기의 끝을 이용하여
상대에게 직선적으로 공격하는 방식이다.

특히 창이나 레이피어처럼 길이가 긴 무기는
무기의 리치를 적극적으로 활용한다.

주요 특징:

- 직선적인 공격 경로
- 무기 끝부분 활용
- 무기의 길이를 이용한 거리 확보
- 좁은 공격선

## 게임 특성

> **찌르기 = 리치와 직선성**

찌르기 기술은 직선 방향의 공격과
무기의 리치를 활용하는 기술에 적합하다.

예:

```text
👤 → □ → 👹
```

일부 찌르기 기술은 기본 공격보다 사거리가 증가할 수 있다.

예:

```text
견제 찌르기
사거리 +1
```

또는 여러 칸을 직선으로 관통하는 기술도 만들 수 있다.

```text
👤 → 👹 → 👹
```

단, 찌르기라고 해서 반드시 명중률이 높거나
위력이 낮은 것은 아니다.

# 3. 타격

## 정의

무기의 질량과 운동량을 이용하여
상대에게 강한 충격을 전달하는 공격 방식.

대표적인 실제 공격 방식은 Strike / Blow 계열이다.

## 대표 무기

- 철퇴
- 망치
- 곤봉
- 봉
- 일부 도끼
- 일부 창
- 일부 폴암

## 실제 무기술의 특징

타격은 목표물을 절단하는 것보다
충격 자체를 전달하는 것이 중요하다.

무기의 질량과 운동량을 이용해
작은 영역에 강한 충격을 집중시킨다.

특히 갑옷이나 방어 장비를 사용하는 상대에게
날붙이와 다른 방식으로 압력을 줄 수 있다.

## 게임 특성

> **타격 = 충격**

타격 타입은 상대의 방어를 무너뜨리는 기술에 적합하다.

일부 타격 기술은 다음 효과를 가질 수 있다.

- 방어 효과 일부 무시
- 방패 방어 효과 감소
- 방어 상태 해제
- 자세 붕괴
- 일시적인 방어력 감소

예:

```text
강타

위력: 130%
명중률: 85%
소모 지구력: 20

효과:
방어 효과 일부 무시
```

타격의 정체성을 단순히 높은 피해량으로 만들기보다는
**방어에 대한 강점**으로 표현한다.

---

# 4. 걸기

## 정의

무기의 돌출된 부분이나 날의 형태를 이용하여
상대의 신체, 무기 또는 방패를 걸어 제어하는 공격 방식.

Hooking / Tripping / Control 계열의 여러 무기술을
게임 시스템상 하나의 타입으로 통합한 것이다.

## 대표 무기

- 낫
- 도끼
- 할버드
- 폴암
- 일부 월도
- 갈고리 구조가 존재하는 장병기

## 실제 무기술의 특징

걸기는 단순히 상대에게 피해를 주는 것이 목적이 아니다.

무기의 구조를 이용하여 상대의

- 팔
- 다리
- 몸
- 무기
- 방패

등을 걸어 움직임을 제어한다.

이를 통해 상대의 균형이나 자세를 무너뜨릴 수 있다.

## 게임 특성

> **걸기 = 물리적 제어**

걸기 타입 기술은 직접적인 피해보다
상대의 위치와 자세를 변화시키는 데 특화된다.

대표 효과:

- 1칸 당기기
- 밀기
- 넘어뜨리기
- 이동력 감소
- 방향 변경
- 방패 해제
- 자세 붕괴

예:

```text
현재

👤 □ 👹

걸기 사용

👤 👹 □
```

적을 자신의 방향으로 1칸 당긴다.

걸기는 [[수호신]]의 악귀 계열 마법이 사용하는 초자연적인 전장 조작과 구분한다.

```text
걸기
= 물리적인 전장 조작

악귀 마법
= 초자연적인 전장 조작
```

---

# 5. 사격

## 정의

활 등의 원거리 무기를 이용하여
투사체를 발사하는 공격 방식.

## 대표 무기

- 각궁
- 장궁
- 컴파운드보우

## 실제 무기술의 특징

사격에서는 다음 요소가 중요하다.

- 거리
- 조준
- 활의 장력과 구조
- 화살의 종류
- 사선
- 목표물과의 위치 관계

## 게임 특성

> **사격 = 거리와 사선**

사격 타입은 원거리에서 적을 공격할 수 있다.

```text
👤 □ □ □ □ 👹
```

단, 사격은 공격 방향의 가장 가까운 상대만 공격할 수 있다.

예:

```text
🏹 → 👹 → 👹
```

첫 번째 적:

```text
공격 가능
```

두 번째 적:

```text
공격 불가
```

앞의 적이 뒤의 적에 대한 사선을 차단한다.

장애물 역시 종류에 따라 사선을 차단할 수 있다.

따라서 원거리 캐릭터는 단순히 거리를 확보하는 것뿐 아니라
**좋은 사선을 확보하는 것**이 중요하다.

# 6. 기술 타입 요약

| 타입 | 핵심 | 게임 특성 |
|---|---|---|
| 베기 | 궤적 | 넓은 공격 궤적을 활용하는 기술 |
| 찌르기 | 리치 | 직선 방향과 무기 길이를 활용하는 기술 |
| 타격 | 충격 | 상대의 방어 효과를 무너뜨리는 기술 |
| 걸기 | 제어 | 상대의 위치·자세를 물리적으로 조작 |
| 사격 | 사선 | 원거리 공격 및 사선 관리 |

기술 타입은 **기술이 어떻게 공격하는가**를 나타낸다.

기술의 강함 자체를 나타내지는 않는다.

# 7. 기술 성능

각 기술은 기본적으로 다음 정보를 가진다.

```text
기술명
기술 타입
기술 위력 또는 효과
기술 명중률
소모 지구력
사거리
공격 범위
부가 효과
```

예:

```text
돌진 찌르기

타입: 찌르기
위력: 160%
명중률: 80%
소모 지구력: 25
사거리: 2
범위: 단일
```

같은 타입이라도 기술에 따라 성능은 달라질 수 있다.

---

# 8. 같은 타입 내 기술 차이

기술 타입에 위력과 명중률을 고정하지 않는다.

예를 들어 모든 찌르기가
`저위력 / 고명중`일 필요는 없다.

## 찌르기 예시

### 견제 찌르기

```text
위력: 80%
명중률: 105%
소모 지구력: 8
```

### 기본 찌르기

```text
위력: 100%
명중률: 100%
소모 지구력: 10
```

### 돌진 찌르기

```text
위력: 160%
명중률: 80%
소모 지구력: 25
```

모두 찌르기지만 역할은 서로 다르다.

## 베기 예시

### 빠른 베기

```text
위력: 80%
명중률: 105%
소모 지구력: 7
```

### 기본 베기

```text
위력: 110%
명중률: 95%
소모 지구력: 10
```

### 대각선 베기

```text
위력: 140%
명중률: 85%
소모 지구력: 18
```

즉,

> **타입은 공격 방법을 결정하고, 기술은 성능을 결정한다.**

# 9. 무기와 기술 타입

하나의 무기는 하나의 기술 타입에만 제한되지 않는다.

무기의 실제 구조와 사용법에 따라 여러 타입의 기술을 사용할 수 있다.

| 무기 | 베기 | 찌르기 | 타격 | 걸기 | 사격 |
|---|:---:|:---:|:---:|:---:|:---:|
| 롱소드 | ● | ● | △ | - | - |
| 검 | ● | ● | - | - | - |
| 레이피어 | △ | ● | - | - | - |
| 철퇴 | - | - | ● | - | - |
| 도끼 | ● | - | △ | ● | - |
| 낫 | ● | △ | - | ● | - |
| 창 | - | ● | △ | - | - |
| 월도 | ● | ● | - | △ | - |
| 폴암 | ● | ● | ● | ● | - |
| 각궁 | - | - | - | - | ● |
| 컴파운드보우 | - | - | - | - | ● |
| 장궁 | - | - | - | - | ● |

- `●` : 주력 기술 타입
- `△` : 일부 기술에서 사용
- `-` : 기본적으로 사용하지 않음

# 10. 무기 카테고리와 기술

같은 무기 카테고리는 기본적인 기술 체계를 공유할 수 있다.

단, 하위 무기의 실제 구조에 따라
사용할 수 있는 기술 타입과 기술 효과가 달라질 수 있다.

예:

```text
도검류

롱소드
→ 베기 + 찌르기

검
→ 베기 중심 + 찌르기

레이피어
→ 찌르기 중심 + 일부 베기
```

따라서 기존의

```text
도검류의 모든 무기가 완전히 동일한 기술 사용
```

구조보다는

```text
무기 카테고리
→ 공통 기술 체계

개별 무기
→ 사용 가능한 기술 / 기술 타입 / 보정 차이
```

구조를 사용한다.

---

# 11. 개별 무기의 특화

개별 무기는 특정 기술 또는 기술 타입에 보정을 가질 수 있다.

예:

```text
검
베기 기술 위력 증가

레이피어
찌르기 기술 명중률 증가

철퇴
타격 기술의 방어 무시 효과 증가

낫
걸기 기술의 이동 조작 효과 증가

창
찌르기 기술 사거리 증가
```

이를 통해 같은 무기 카테고리 안에서도
하위 무기마다 플레이 스타일이 달라진다.

# 12. 지구력

기술에는 별도의 사용 횟수를 두지 않는다.

대신 [[능력치]]의 지구력을 사용한다.

```text
기술 사용
→
지구력 감소
```

강력하거나 복잡한 기술일수록
일반적으로 더 많은 지구력을 소비한다.

## 지구력 회복

다음 행동을 통해 지구력을 회복할 수 있다.

- 무행동
- 회복 행동
- 일부 기술 또는 마법

## 지구력 부족

지구력이 낮아지면 공격 효율이 감소한다.

따라서 플레이어는

```text
강력한 기술을 연속 사용
```

하는 것과

```text
지구력을 관리하며 장기전 수행
```

사이에서 선택해야 한다.

# 13. 반격

반격 역시 기술 사용과 마찬가지로 지구력을 소비한다.

반격 가능 여부는 다음 요소의 영향을 받는다.

- 공격 거리
- 자신의 무기 리치
- 상대 무기 리치
- 무기 종류
- 현재 지구력
- 상태 이상

## 리치 차이

근거리 전투에서 상대의 무기 리치가 자신의 무기 리치보다 길 경우
상황에 따라 반격이 제한될 수 있다.

예:

```text
창 → 단검

창의 리치 > 단검의 리치

단검 사용자는 즉시 반격 불가
```

따라서 장병기는 거리 통제에 강하고,
짧은 무기는 기동성을 활용하여 거리를 좁혀야 한다.

## 원거리

원거리 무기는 기본적으로 근거리 반격을 할 수 없다.

# 14. 리치와 이동력

무기의 리치가 길수록 전투 거리에서 유리하다.

대신 긴 무기는 캐릭터의 이동력에 더 큰 부담을 줄 수 있다.

```text
긴 무기
→ 높은 리치
→ 이동력 감소량 증가

짧은 무기
→ 낮은 리치
→ 이동력 감소량 감소
```

따라서 무기 선택은 단순한 공격력 선택이 아니라

```text
위력
+
기술
+
리치
+
이동력
+
반격 능력
```

을 함께 고려하는 선택이 된다.

# 15. 마스터리

기존의 `칼날 정렬`처럼 베기와 찌르기만을 대상으로 하는 마스터리에서 확장한다.

마스터리는 캐릭터가 특정 공격 방식을 얼마나 능숙하게 사용하는지를 나타낸다.

기본적으로 다음 기술 타입별 마스터리를 사용할 수 있다.

```text
베기 숙련
찌르기 숙련
타격 숙련
걸기 숙련
사격 숙련
```

단, 캐릭터가 현재 사용하는 무기로 사용할 수 없는 기술 타입은
실질적으로 활용할 수 없다.

예:

```text
철퇴
→ 타격 숙련 활용

창
→ 찌르기 숙련 중심

폴암
→ 베기 / 찌르기 / 타격 / 걸기 숙련 활용 가능
```

마스터리의 구체적인 성장 방식과 효과는 별도 시스템에서 정의한다.

# 16. 기술 설계 원칙

새로운 기술을 만들 때 다음 순서로 설계한다.

```text
1. 실제 무기 동작 결정
↓
2. 기술 타입 결정
↓
3. 기술의 전술적 목적 결정
↓
4. 위력 결정
↓
5. 명중률 결정
↓
6. 소모 지구력 결정
↓
7. 사거리 / 범위 결정
↓
8. 부가 효과 결정
```

예를 들어 창의 기술을 만든다면:

```text
실제 동작
→ 긴 창을 이용한 강한 직선 찌르기

타입
→ 찌르기

전술적 목적
→ 고위력 공격

위력
→ 160%

명중률
→ 80%

소모 지구력
→ 25

사거리
→ 2

결과
→ 돌진 찌르기
```

이 방식을 사용하면 실제 무기술의 특성을 유지하면서
SRPG에 필요한 밸런스를 자유롭게 조절할 수 있다.

# 핵심 정리

본 게임에서 공격 기술은 다음 5가지 타입을 사용한다.

```text
베기 = 궤적
찌르기 = 리치와 직선성
타격 = 충격
걸기 = 물리적 제어
사격 = 거리와 사선
```

그러나 타입 자체가 기술의 강함을 결정하지 않는다.

```text
기술 타입
→ 공격 방식과 전술적 성질

기술 위력
→ 개별 기술에서 결정

기술 명중률
→ 개별 기술에서 결정

소모 지구력
→ 개별 기술에서 결정
```

따라서 같은 찌르기라도

```text
견제 찌르기
기본 찌르기
돌진 찌르기
```

처럼 완전히 다른 역할을 가질 수 있다.

이를 통해 실제 무기술의 다양성을 유지하면서도
SRPG에서 각 기술과 무기의 전술적 차이를 명확하게 만든다.
