# 기술 시스템

## 기본 원칙

공격 기술 타입은 근거리와 원거리 무기의 운용 방식에 따라 다음과 같이 구분한다.

```text
근거리 기술
├─ 휘두르기 (Swing)
└─ 뻗기 (Thrust)

원거리 기술
└─ 사격 (Shot)
```

---

# 1. 근거리 기본 사거리

근거리 기술의 사거리는 기술군이 아니라 장착한 장비의 리치 태그가 결정한다.

| 리치 | 적용 장비 | 공격 가능 거리 | 거리별 위력 |
|---|---|---:|---|
| 단거리 | 검·도·레이피어·철퇴·도끼·낫의 짧은 형태 | 1칸 | 거리 1에서 100% |
| 중거리 | 위 기술군의 긴 형태 및 모든 창·월도·폴암 | 1~2칸 | 거리 1에서 70%, 거리 2에서 100% |

- 장병기는 항상 중거리다.
- 같은 기술도 장착 장비가 단거리면 1칸, 중거리면 1~2칸으로 판정한다.
- 근접 공격은 상·하·좌·우 직선 방향으로만 가능하며 대각선은 허용하지 않는다.
- 거리 2를 공격할 때 같은 방향의 거리 1칸을 다른 유닛이 점유하면 건너뛸 수 없다. 관통처럼 별도 규칙이 있는 기술만 예외다.
- 휘두르기 방향 범위는 장착 장비의 리치까지 확장한다.
- 거리 보정은 기본 공격·액티브 기술·반격 피해에 적용하며 상태 효과에는 적용하지 않는다.

---

# 2. 휘두르기 (Swing)

> **휘두르기 = 낮은 개별 위력 + 인접 방향 범위 공격**

휘두르기의 공격 판정은 시전자 기준 `전방 / 좌측 / 우측 / 후방` 4개 인접 방향 안에서 정한다.

## 비회전 휘두르기

일반 베기, 횡베기, 내려치기처럼 시전자가 몸을 완전히 회전하지 않는 기술은 **후방을 공격할 수 없다.**

따라서 일반 비회전 휘두르기의 최대 범위는 다음과 같다.

```text
전방 + 좌측 + 우측
```

레벨이 올라가도 후방은 추가하지 않는다.

## 걸기형 단일 제어 예외

도끼의 `찍어당기기`, 낫의 `걸어당기기`, 폴암의 `갈고리 당기기`처럼 갈고리·날로 한 대상을 거는 기술은 공격 동작이 휘두르기 형태여도 **사거리 1의 단일 대상 제어 기술**로 처리한다.

```text
걸기형 단일 제어
= 타입: 휘두르기 (Swing)
= 사거리: 1
= 대상: 인접 적 1명
= 효과: 넘어짐
```

### 넘어짐

무기로 상대를 걸어 균형을 무너뜨린 상태다.

- 지속: 1턴
- 효과: 민첩성 감소 + 반격 불가
- 반격 불가는 모든 기술 레벨에서 1턴 고정
- 민첩성 감소량은 기술 레벨에 따라 증가
- 대상의 위치는 변경하지 않는다.

| Lv | 민첩성 감소 | 반격 불가 |
|---:|---:|---|
| 1 | -10% | 1턴 |
| 2 | -11% | 1턴 |
| 3 | -12% | 1턴 |
| 4 | -13% | 1턴 |
| 5 | -14% | 1턴 |
| 6 | -16% | 1턴 |
| 7 | -17% | 1턴 |
| 8 | -19% | 1턴 |
| 9 | -20% | 1턴 |
| 10 | -22% | 1턴 |

적의 회피 성능을 낮추는 기술 효과가 필요한 경우 **직접 회피율 감소를 사용하지 않고 민첩성 감소로 통일**한다.

## 회전 휘두르기

`회전베기`, `대회전`, `회전타격`, `회전수확`처럼 **몸과 무기를 한 바퀴 돌리는 동작이 명확한 기술만 후방을 공격할 수 있다.**

```text
회전 기술 성장 예
Lv.1~4 → 전방 + 좌측 + 우측
Lv.5~10 → 전방 + 좌측 + 우측 + 후방
```

회전 기술은 후방까지 공격할 수 있는 대신 일반 휘두르기보다 높은 ST 소모를 가질 수 있다.

## 휘두르기형 무기 구성 원칙

휘두르기를 주력으로 사용하는 무기는 최소 하나의 회전 공격 기술을 갖는다.

회전 기술이 없다면 **기본 기술은 유지**하고, 나머지 액티브 기술 중 역할이 가장 단순하거나 다른 기술과 겹치는 기술을 회전 기술로 교체한다.

# 3. 뻗기 (Thrust)

> **뻗기 = 높은 위력 + 직선 단일 공격**

- 단거리 무기는 정면 1칸, 중거리 무기는 정면 1~2칸의 단일 적을 공격한다.
- 중거리 무기는 거리 1에서 위력 70%, 거리 2에서 위력 100%를 적용한다.
- 대각선 적은 공격할 수 없다.
- 기술 레벨 상승 시 위력, 방어 무시, 연속 공격 등 기존 단일 대상 성능을 강화한다.

## 관통 패시브

레이피어·창의 `관통`은 중거리 직접 공격과 별개로 직선 뒤의 적에게 추가 피해를 주는 패시브다.

```text
● → A → B
```

뻗기 기술이 직선상의 첫 대상 A에 적중하면 일정 확률로 A의 직선 뒤 1칸에 있는 B에게 원 피해의 일정 비율만큼 추가 피해를 준다. 직접 공격이 거리 1에서 발생했다면 70% 거리 보정을 먼저 적용한 피해를 원 피해로 삼는다. 대각선에는 발동하지 않으며 관통 피해가 다시 관통을 일으키지 않는다.

---

# 4. 사격 (Shot)

활 등 원거리 무기의 모든 공격 기술은 `사격` 타입으로 통일한다.

## 원거리 기본 사거리

원거리 액티브 기술은 **기술마다 사거리가 달라지지 않고, 장착한 무기의 기본 사거리**를 사용한다.

| 무기 | 기본 사거리 | 운용 특성 |
|---|---:|---|
| 각궁 | 2칸 | 기동성 / 빠른 사격 |
| 컴파운드보우 | 2칸 | 안정적인 정밀 사격 / 제압 |
| 장궁 | 3칸 | 최장거리 / 고위력 / 관통 |

- 같은 무기에서 사용하는 모든 액티브 사격 기술은 기본적으로 동일한 사거리를 사용한다.
- 기술 레벨 상승으로 사거리가 증가하지 않는다.
- 기술의 개성은 위력, ST, 공격 범위 형태, 방어 무시, 이동 등으로 구분한다.
- 원거리 사거리는 시전자 기준 상·하·좌·우 이동 거리와 동일한 **맨해튼 거리**로 계산한다.
- 범위기가 아닌 단일 사격은 선택한 공격 방향의 기본 사거리 안에서 **시전자와 가장 가까운 적 하나만** 지정할 수 있다. 더 가까운 적을 건너뛰어 뒤의 적을 지정할 수 없다.
- 범위 사격은 기본 사거리 안의 기준 칸 또는 방향을 지정한 뒤 기술에 정의된 범위에 피해를 준다.

## 사격 범위

사격은 기술별로 단일 또는 범위 공격이 될 수 있다.

```text
단일 사격
→ 기본 사거리 안에서 적 1명 지정

직선 사격
→ 기본 사거리 안에서 지정한 방향의 직선 칸 공격

지정 범위 사격
→ 기본 사거리 안의 한 칸을 중심점으로 지정
→ 중심점 주변의 기술 범위 공격

확산 / 제압 사격
→ 기본 사거리 안에서 방향 지정
→ 해당 방향의 기술별 범위 공격
```

범위 안에 포함된 적은 모두 피격되며 별도의 최대 피격 인원 수는 두지 않는다.

---

# 5. 기술 정보

모든 액티브 기술은 다음 정보를 가진다.

```text
기술명
기술 타입
기술 위력 또는 효과
소모 지구력(ST)
사거리
공격 범위
부가 효과
```

기술별 명중률과 최대 공격 대상 수는 사용하지 않는다. 실제 피격 대상 수는 공격 판정 칸에 포함된 적의 수로 결정한다.

---

# 6. 기술 레벨

각 기술은 `Lv.1 ~ Lv.10`까지 강화한다.

```text
기술 레벨 상승
→ 기존 성능 상승
→ 지정 레벨에서만 ST 소모 상승
```

- 비회전 휘두르기: 전방·좌측·우측 안에서만 범위 확대
- 걸기형 단일 제어: 단일 대상 유지, 위력·민첩성 감소 강화
- 회전 휘두르기: 일정 레벨부터 후방 포함 가능
- 뻗기: 무기 기본 사거리를 유지하며 단일 성능 강화
- 사격: **무기 기본 사거리는 유지**하며 위력·범위 형태·부가 효과 강화
- 위력은 매 레벨 조금씩 상승하되 Lv.10에서 마무리 보정을 받는다.
- ST 소모는 매 레벨 증가하지 않고 원칙적으로 Lv.3·5·7·9에서만 상승한다.
- 짝수 레벨은 직전 홀수 레벨의 ST를 유지한다.

---

# 7. 기술 습득과 장착

- 캐릭터가 배울 수 있는 무기 기술 수에는 제한이 없다.
- 고위력 기술은 같은 무기의 저위력 기술을 선행 조건으로 요구한다.
- 캐릭터 레벨에 따른 일반 무기 기술 해금 제한은 없다.
- 전투에 장착할 수 있는 일반 무기 기술은 최대 4개다.
- 패시브와 마스터리는 장착 수에 포함하지 않는다.
- 영력 각성으로 얻은 기술은 4개 제한과 별도 슬롯을 사용한다.
- 전투 중 장착 기술을 교체할 수 없다.

# 9. 지구력

기술에는 별도의 사용 횟수를 두지 않고 [[능력치]]의 지구력을 사용한다. 기술이 강해질수록 더 많은 ST를 소비한다.

---

# 10. 마스터리

근거리 마스터리는 **무기 종류 + 리치** 조합으로 관리한다.

- 검·도·레이피어·철퇴·도끼·낫은 단거리와 중거리 마스터리를 각각 가질 수 있다.
- 창·월도·폴암은 중거리 마스터리만 가진다.
- 단거리 트랙: 초기 숙련도 100 / 레벨당 SP 1 / Lv.10 숙련도 보너스 +28%
- 중거리 트랙: 초기 숙련도 80 / 레벨당 SP 2 / Lv.10 숙련도 보너스 +20%
- 같은 기술군이라도 두 리치의 숙련도와 SP 투자는 공유하지 않는다.
- 활은 무기별 일반 마스터리를 사용한다.

# 핵심 정리

```text
근거리 액티브 기술
= 단거리 무기: 사거리 1
= 중거리 무기: 사거리 1~2
= 중거리 거리 1 위력 70% / 거리 2 위력 100%

비회전 휘두르기
= 전방 / 좌측 / 우측까지만
= 후방 공격 불가

걸기형 단일 제어
= 휘두르기 타입 유지
= 단일 대상
= 넘어짐 부여
= 1턴 민첩성 감소 + 반격 불가

회전 휘두르기
= 후방 공격 가능

뻗기
= 단거리 무기는 사거리 1
= 중거리 무기는 사거리 1~2
= 관통은 직접 사거리와 별도의 후방 추가 피해

원거리 사격
= 무기별 기본 사거리 고정
각궁 2 / 컴파운드보우 2 / 장궁 3
= 기술 레벨로 사거리 증가 없음
= 기술별 단일 / 범위 형태로 차별화

숙련 성장 분류
= 단거리 리치와 활: 초기 숙련도 100 / 마스터리 SP 1 / Lv.10 +28%
= 중거리 리치: 초기 숙련도 80 / 마스터리 SP 2 / Lv.10 +20%
= 활의 발사 사거리와 중거리 근접 규칙은 별개
```
