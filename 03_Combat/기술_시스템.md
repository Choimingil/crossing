# 기술 시스템

## 기본 원칙

공격 기술 타입은 근거리와 원거리 무기의 운용 방식에 따라 다음과 같이 구분한다.

```text
근거리 기술
├─ 휘두르기 (Swing)
└─ 뻗기 (Thrust)

원거리 기술
└─ 사격 (Shot)
```

---

# 1. 근거리 기본 사거리

모든 근거리 액티브 기술의 사거리는 **1칸으로 고정**한다.

사거리 1은 캐릭터의 기본 이동과 같은 방식으로 계산하며 시전자 기준 상·하·좌·우 인접 4칸만 포함한다.

```text
  ■
■ ● ■
  ■
```

- `●`: 시전자
- `■`: 근거리 기본 사거리 1칸
- 대각선은 포함하지 않는다.
- 맨해튼 거리 1을 기준으로 한다.
- 근거리 기술 자체가 사거리 2 이상으로 증가하는 예외는 두지 않는다.

레이피어·창처럼 실제 리치가 긴 무기의 장점은 액티브 기술의 사거리 증가가 아니라 패시브 효과로 표현한다.

대표 예시는 `관통`이다.

```text
● → A → B

● = 시전자
A = 사거리 1의 최초 피격 대상
B = A의 직선 뒤 1칸에 있는 추가 피격 후보
```

즉 시전자는 항상 A까지만 직접 공격하며, B에 대한 피해는 무기의 리치 특성을 표현하는 추가 효과로 처리한다.

---

# 2. 휘두르기 (Swing)

근거리 무기를 넓은 궤적으로 휘둘러 둘 이상의 방향을 공격하는 기술이다.

> **휘두르기 = 낮은 개별 위력 + 인접 방향 범위 공격**

휘두르기의 공격 판정은 시전자 기준 상·하·좌·우 인접 4칸 안에서 정한다.

```text
횡방향
좌측 + 우측

전방 휩쓸기
전방 + 좌측 + 우측

회전 공격
전방 + 좌측 + 우측 + 후방
```

범위 안에 적이 여러 명 있으면 모두 피격된다. 별도의 최대 피격 인원 수는 두지 않는다.

기술 레벨이 오르면 네 인접 방향 안에서 공격 판정 방향이 확대될 수 있으며 사거리 자체는 증가하지 않는다.

---

# 3. 뻗기 (Thrust)

무기 끝이나 직선 동작을 한 목표에 집중하는 근거리 기술이다.

> **뻗기 = 높은 위력 + 사거리 1의 단일 공격**

- 모든 뻗기 액티브 기술의 직접 사거리는 1칸이다.
- 기본적으로 캐릭터가 바라보는 정면 인접 1칸의 단일 적을 공격한다.
- 대각선 적은 공격할 수 없다.
- 기술 레벨 상승 시 사거리가 아니라 위력, 방어 무시, 이동, 제어 등 기술 고유 성능이 강화된다.
- 긴 무기의 리치는 `관통` 같은 패시브로 표현한다.

## 관통 패시브 원칙

레이피어·창 등 직선 관통에 적합한 무기는 패시브 `관통`을 가질 수 있다.

뻗기 기술로 최초 대상 A에게 피해를 입히면 일정 확률로 A의 뒤쪽 직선 1칸에 있는 적 B에게 원 피해의 일부를 추가로 준다.

- B는 A와 같은 직선상에 있어야 한다.
- 대각선에는 발동하지 않는다.
- B가 없으면 추가 피해가 발생하지 않는다.
- 관통 피해에서 다시 관통이 연쇄 발동하지 않는다.

---

# 4. 사격 (Shot)

활 등 원거리 무기의 모든 공격 기술은 `사격` 타입으로 통일한다.

사격은 기술에 따라 단일 공격과 범위 공격을 모두 사용할 수 있다.

- 단일 사격: 한 대상을 지정
- 직선 사격: 지정 방향의 직선 칸 공격
- 지정 범위 사격: 선택 지점을 중심으로 범위 공격
- 부채꼴/확산 사격: 지정 방향의 여러 칸 공격

원거리 범위는 근거리의 인접 4칸 규칙을 적용하지 않으며 각 기술의 `사거리 + 공격 범위`로 정의한다.

---

# 5. 기술 정보

모든 액티브 기술은 기본적으로 다음 정보를 가진다.

```text
기술명
기술 타입
기술 위력 또는 효과
소모 지구력(ST)
사거리
공격 범위
부가 효과
```

기술별 명중률과 최대 공격 대상 수는 사용하지 않는다.

실제 피격 대상 수는 공격 판정 칸에 포함된 적의 수로 결정한다.

---

# 6. 기술 레벨

각 기술은 `Lv.1 ~ Lv.5`까지 강화할 수 있다.

```text
기술 레벨 상승
→ 기존 성능 상승
→ ST 소모 상승
```

휘두르기는 인접 4방향 안에서 범위가 확대될 수 있다.
뻗기는 사거리 1을 유지하면서 단일 위력과 기존 부가 성능을 강화한다.
사격은 기술별 단일/범위 특성을 유지하면서 성능이 강화된다.

# 8. 지구력

기술에는 별도의 사용 횟수를 두지 않고 [[능력치]]의 지구력을 사용한다.

기술이 강해질수록 더 많은 ST를 소비한다.

---

# 9. 마스터리

마스터리는 기술 타입별이 아니라 **무기별 마스터리**로 사용한다.

기본 효과:

- 해당 무기의 숙련도 증가
- 해당 무기로 사용하는 기술의 전반적인 성능 소폭 증가

# 핵심 정리

```text
근거리 액티브 기술
= 전부 사거리 1
= 상 / 하 / 좌 / 우 인접 칸
= 대각선 제외

휘두르기
= 인접 4방향 조합 범위 공격

뻗기
= 사거리 1의 직선 단일 공격

긴 무기의 리치
= 액티브 사거리 증가가 아니라 관통 등 패시브로 표현

사격
= 원거리 전용
= 기술별 단일 / 범위 정의
```
