# 도끼 기술

[[무기별_기술/개요|무기별 기술 개요]]

## 개요
휘두르기 중심의 중병기. 시전자 주변 1칸에서 전방·측면·회전 범위를 강하게 쓸어 다수의 적을 공격한다.

## 패시브
### 중량 활용
높은 ST 상태에서 휘두르기 위력 증가: +4% / +6% / +8% / +10% / +13%.

### 상처 확대
피해받은 적에 대한 위력 증가: +3% / +5% / +7% / +9% / +12%.
