# 각궁 기술

[[무기별_기술/개요|무기별 기술 개요]]

## 개요
기동성과 연속 사격에 특화된 원거리 무기. 모든 공격 기술은 `사격(Shot)` 타입이며 **기본 사거리 2칸**을 공통으로 사용한다.

- 모든 액티브 기술 사거리: 2칸
- 기술 레벨 상승으로 사거리는 증가하지 않는다.
- 사거리는 시전자 기준 맨해튼 거리로 계산한다.
- 장점: 낮은 ST, 이동 연계, 빠른 연사, 근중거리 범위 대응
- 단점: 세 활 중 기본 위력과 최대 사거리가 낮다.

## 패시브
### 기마궁술 응용
이동 후 사용하는 사격 기술 ST 증가 페널티 완화: 10% / 20% / 30% / 40% / 50%.

### 빠른 장전
연속 사격 시 다음 사격 ST 감소: -1 / -1 / -2 / -2 / -3.
