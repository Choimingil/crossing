# 각궁 기술

[[무기별_기술/개요|무기별 기술 개요]]

## 개요
기동성을 살린 원거리 무기. 모든 공격 기술은 `사격(Shot)` 타입이며 기술별로 단일 또는 범위 공격을 사용한다.

## 패시브
### 기마궁술 응용
이동 후 사용하는 사격 기술 ST 증가 페널티 완화: 10% / 20% / 30% / 40% / 50%.

### 빠른 장전
연속 사격 시 다음 사격 ST 감소: -1 / -1 / -2 / -2 / -3.
