# 각궁 기술

[[개요]]

## 개요
이동과 사격을 결합하는 기동형 원거리 무기. 모든 공격은 한 목표에 화살을 집중하는 **뻗기 (Thrust)** 타입이다.

## 패시브
### 기마궁술 응용
이동 후 사용하는 뻗기 기술의 ST 추가 부담 감소: Lv.1~5 `10% / 20% / 30% / 40% / 50%`.

### 빠른 장전
연속 사격 시 다음 뻗기 기술 ST 감소: Lv.1~5 `-1 / -1 / -2 / -2 / -3`.
