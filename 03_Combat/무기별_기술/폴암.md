# 폴암 기술

[[무기별_기술/개요|무기별 기술 개요]]

## 개요
휘두르기와 뻗기를 모두 사용하는 다기능 장병기. 범위 기술은 시전자 주변 1칸을 방향형으로 사용한다.

## 패시브
### 무기 전환
서로 다른 타입을 연속 사용했을 때 다음 기술 ST 감소: -1 / -1 / -2 / -2 / -3.

### 거리 지배
자신보다 리치가 짧은 적 상대 기술 위력 보너스: +2% / +4% / +6% / +8% / +10%.
