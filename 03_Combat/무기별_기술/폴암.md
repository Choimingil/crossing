# 폴암 기술

[[무기별_기술]]

## 개요

## 패시브
### 무기 전환
서로 다른 타입을 연속 사용했을 때 다음 기술 ST 감소: -1 / -1 / -2 / -2 / -3.
### 거리 지배
자신보다 리치가 짧은 적 상대 명중 보너스: +2% / +4% / +6% / +8% / +10%.
