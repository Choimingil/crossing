# 폴암 기술

[[무기별_기술/개요|무기별 기술 개요]]

## 개요
휘두르기와 뻗기를 함께 사용하는 다기능 장병기. 비회전 휘두르기는 전방·좌우까지만 공격한다. `갈고리 당기기`는 갈고리로 상대의 행동을 방해하는 단일 대상 제어 기술로 사용한다.

### 갈고리 당기기
- 타입: 휘두르기 (Swing)
- 판정: **단일 대상**
- 대상: 전방·좌측·우측 중 사거리 1 내 적 1명
- 효과: 갈고리로 무기나 신체를 걸어 행동을 끊는다. 대상의 다음 기술 ST 소모량을 증가시킨다.
- 규칙: 대상의 위치는 변경하지 않으며 기술 레벨이 상승해도 대상 수는 증가하지 않는다.

|1|55%|+2|13|인접 적 1명|
|2|61%|+3|14|인접 적 1명|
|3|67%|+4|15|인접 적 1명|
|4|73%|+5|17|인접 적 1명|

## 패시브
### 무기 전환
서로 다른 타입을 연속 사용했을 때 다음 기술 ST 감소: -1 / -1 / -2 / -2 / -3.
### 거리 지배
자신보다 리치가 짧은 적 상대 기술 위력 증가: +2% / +4% / +6% / +8% / +10%.
