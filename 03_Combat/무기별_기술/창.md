# 창 기술

[[개요]]

## 개요
긴 리치를 이용해 한 대상을 집중 공격하는 뻗기 특화 장병기. 자루를 이용한 일부 휘두르기 기술로 근접 다수 대응도 가능하다.

## 패시브
### 거리 유지
리치가 짧은 적에게 받는 피해 감소: Lv.1~5 `3% / 5% / 7% / 9% / 12%`.

### 선제 견제
접근하는 적에게 사용하는 뻗기 기술 위력 보정: Lv.1~5 `+0% / +5% / +10% / +15% / +20%`.
