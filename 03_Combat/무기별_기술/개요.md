# 무기별 기술 개요

각 무기의 기술 구성, 성장 규칙, 역할과 상세 기술 문서 연결을 관리한다.

- [[무기_시스템]]

## 기본 규칙

각 무기는 총 **8개의 기술**을 가진다.

- 액티브 기술: 5개
- 패시브 기술: 2개
- 마스터리: 1개

액티브 기술은 다음 정보를 가진다.

- 기술 타입
- 기술 위력 또는 효과
- 소모 지구력(ST)
- 사거리
- 공격 범위
- 부가 효과

기술별 명중률과 최대 공격 대상 수는 사용하지 않는다.

실제 피격 대상 수는 **기술의 공격 범위에 포함된 적의 수**로 결정한다.

## 기술 타입

### 근거리

| 타입 | 영문 | 핵심 역할 |
|---|---|---|
| 휘두르기 | Swing | 낮은 개별 위력 / 방향형 범위 공격 |
| 뻗기 | Thrust | 높은 위력 / 단일 공격 |

#### 휘두르기

- 시전자 주변 1칸을 기본 범위로 사용한다.
- 기술마다 전방, 좌우, 부채꼴, 회전 등 공격 방향이 다르다.
- 범위 안에 존재하는 모든 적이 피격된다.
- 기술 레벨 상승 시 기존 방향성을 유지하면서 공격 판정 칸이 확대될 수 있다.

#### 뻗기

- 단일 대상을 공격한다.
- 휘두르기보다 개별 위력이 높다.
- 레벨 상승 시 위력, 리치, 방어 무시 등 단일 대상 성능이 강화된다.

### 원거리

원거리 무기는 `휘두르기 / 뻗기`를 사용하지 않고 모든 공격 기술을 **사격(Shot)**으로 분류한다.

사격은 기술별로 단일 또는 범위 공격이 될 수 있다.

- 단일 사격: 한 대상을 지정
- 직선 사격: 지정 방향의 직선 칸 공격
- 지정 범위 사격: 선택 지점을 중심으로 범위 공격
- 부채꼴 사격: 지정 방향으로 여러 칸 공격

원거리 기술은 `사거리 + 공격 범위`로 피격 위치를 결정한다.

---

## 기술 성장 규칙

모든 기술은 `Lv.1 ~ Lv.5`까지 강화할 수 있다.

```text
기술 레벨 상승
→ 기존 성능 상승
→ ST 소모 상승
```

휘두르기와 범위 사격은 기존 범위 형태를 유지하면서 공격 판정 칸이 확대될 수 있다.

뻗기와 단일 사격은 공격 대상 수를 늘리지 않고 위력과 기존 부가 성능을 강화한다.

패시브와 마스터리는 ST를 직접 소비하지 않는다.

---

## 마스터리

마스터리는 기술 타입별이 아니라 **무기별 마스터리**로 사용한다.

기본 효과:

- 해당 무기의 숙련도 증가
- 해당 무기로 사용하는 기술의 전반적인 성능 소폭 증가

## 시스템 구조

```text
캐릭터
│
├─ 능력치
├─ 오행
├─ 수호신
├─ 주무기
│   └─ 사용 가능한 기술
├─ 기술 타입
│   ├─ 근거리
│   │   ├─ 휘두르기 (Swing)
│   │   └─ 뻗기 (Thrust)
│   └─ 원거리
│       └─ 사격 (Shot)
└─ 기술 포인트
    └─ 액티브 / 패시브 / 마스터리 강화
```

**음양 시스템은 사용하지 않는다.**
