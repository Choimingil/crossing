# 무기별 기술 개요

각 무기의 기술 구성, 성장 규칙, 역할과 상세 기술 문서 연결을 관리한다.

## 기본 규칙

각 무기는 총 **8개의 기술**을 가진다.

- 액티브 기술: 5개
- 패시브 기술: 2개
- 마스터리: 1개

액티브 기술은 다음 정보를 가진다.

- 기술 타입
- 기술 위력 또는 효과
- 소모 지구력(ST)
- 사거리
- 최대 공격 대상 수
- 부가 효과

**기술별 명중률 항목은 사용하지 않는다.**

---

## 기술 타입

공격 기술 타입은 다음 2개로 통일한다.

| 타입 | 영문 | 핵심 역할 |
|---|---|---|
| 휘두르기 | Swing | 낮은 위력 / 범위 공격 |
| 뻗기 | Thrust | 높은 위력 / 단일 공격 |

### 휘두르기

- 복수의 적을 공격한다.
- 뻗기보다 개별 대상 위력이 낮다.
- 기술 레벨이 오를수록 최대 공격 대상 수가 증가한다.

일반적인 성장 기준:

| Lv | 최대 대상 |
|---|---:|
| 1 | 2명 |
| 2 | 2명 |
| 3 | 3명 |
| 4 | 3명 |
| 5 | 4명 |

광역 특화 기술은 `3 → 3 → 4 → 4 → 5명`처럼 더 높은 대상 수를 사용할 수 있다.

### 뻗기

- 최대 공격 대상은 항상 1명이다.
- 휘두르기보다 위력이 높다.
- 레벨 상승 시 위력, 사거리, 방어 무시 등 기존 단일 대상 성능이 강화된다.

---

## 기술 성장 규칙

모든 기술은 `Lv.1 ~ Lv.5`까지 강화할 수 있다.

기술 포인트를 투자하여 레벨이 오르면 기존 성능이 점진적으로 상승한다.

```text
기술 레벨 상승
→ 기존 성능 상승
→ ST 소모 상승
```

휘두르기는 추가로 최대 공격 대상 수가 증가한다.

```text
휘두르기 레벨 상승
→ 위력 상승
→ 최대 공격 대상 수 증가
→ ST 상승
```

뻗기는 대상 수를 1명으로 유지한다.

```text
뻗기 레벨 상승
→ 단일 위력 상승
→ 기존 부가 성능 강화
→ ST 상승
```

패시브와 마스터리는 ST를 직접 소비하지 않는다.

---

## 마스터리

마스터리는 기술 타입별이 아니라 **무기별 마스터리**로 사용한다.

기본 효과:

- 해당 무기의 숙련도 증가
- 해당 무기로 사용하는 기술의 전반적인 성능 소폭 증가

기술 명중률 증가 효과는 사용하지 않는다.

## 시스템 구조

```text
캐릭터
│
├─ 능력치
├─ 오행
├─ 수호신
├─ 주무기
│   └─ 사용 가능한 기술
├─ 기술 타입
│   ├─ 휘두르기 (Swing)
│   └─ 뻗기 (Thrust)
└─ 기술 포인트
    └─ 액티브 / 패시브 / 마스터리 강화
```

**음양 시스템은 사용하지 않는다.**
