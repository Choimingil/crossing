# 무기별 기술 개요

각 무기의 기술 구성, 성장 규칙, 역할과 상세 기술 문서 연결을 관리한다.

## 기본 규칙

각 무기는 총 **8개의 기술**을 가진다.

- 액티브 기술: 5개
- 패시브 기술: 2개
- 마스터리: 1개

액티브 기술은 다음 정보를 가진다.

- 기술 타입
- 기술 위력 또는 효과
- 기술 명중률
- 소모 지구력

패시브 기술은 별도의 지구력을 소비하지 않는다.

모든 기술은 **기술 포인트(TP)**를 투자하여 강화할 수 있다.

---

## 기술 성장 규칙

각 기술은 기본적으로 `Lv.1 ~ Lv.5`까지 강화할 수 있다.

기술 레벨에는 특정 레벨에서만 해금되는 고정 스텝이나 특수 효과를 두지 않는다.

기술 포인트를 투자하여 레벨이 오르면 **기술의 기존 성능이 전반적으로 점진 상승**한다.

액티브 기술은 레벨 상승에 따라 기술의 성격에 맞는 성능 수치가 함께 증가한다.

- 공격 기술: 위력 증가
- 제어 기술: 제어 효과 또는 성공 성능 증가
- 방어 무시 기술: 방어 무시 성능 증가
- 이동·사거리 관련 기술: 기존 효과의 효율 증가
- 기술 명중률: 필요에 따라 소폭 증가 가능

단, 기술의 기본 정체성·공격 범위·작동 방식은 레벨업만으로 변경하지 않는다. 새로운 효과나 별도의 기능을 특정 레벨에 해금하는 방식도 기본적으로 사용하지 않는다.

### 지구력 소모 증가

기술이 강해질수록 그 기술을 구사하는 데 필요한 부담도 증가한다.

따라서 **액티브 기술의 레벨이 상승하면 성능과 함께 소모 지구력(ST)도 증가한다.**

```text
기술 레벨 상승
→ 기존 기술 성능 상승
→ 소모 지구력 증가
```

즉 기술 강화는 다음과 같은 선택을 만든다.

```text
낮은 기술 레벨
→ 성능이 낮음
→ 지구력 소모가 적음
→ 반복 사용에 유리

높은 기술 레벨
→ 성능이 높음
→ 지구력 소모가 큼
→ 순간적인 전투 효율이 높음
```

각 무기 상세 문서의 Lv.1 수치를 기준으로 레벨별 성장값을 적용한다.

기술별 성장 폭은 역할과 밸런스에 따라 개별 조정할 수 있지만, 기본 원칙은 `성능 상승 + ST 소모 상승`으로 통일한다.

패시브 기술과 마스터리는 지구력을 직접 소비하지 않으므로 레벨 상승에 따른 ST 증가를 적용하지 않는다.

## 마스터리

마스터리는 각 무기의 최종 성장 패시브다.

기술 타입별 마스터리가 아니라 **무기별 마스터리**로 통일한다.

모든 무기 마스터리의 기본 효과는 다음 두 가지다.

- 해당 무기의 숙련도 증가
- 해당 무기로 사용하는 기술의 명중률 증가

일반 기술과 마찬가지로 기술 포인트를 투자하여 강화하며, 일반 기술보다 높은 기술 포인트를 요구한다.

마스터리 레벨이 오를수록 무기 숙련도와 해당 무기 기술 명중률 보너스가 함께 증가한다.

구체적인 레벨별 수치는 각 무기의 상세 기술 문서에서 정의한다.

## 시스템 구조

캐릭터의 전투 구성은 다음과 같다.

```text
캐릭터
│
├─ 능력치
│
├─ 오행
│   └─ 영력 속성 / 상성
│
├─ 수호신
│   └─ 마법 특성
│
├─ 주무기
│   └─ 사용 가능한 기술
│
├─ 기술 타입
│   ├─ 베기
│   ├─ 찌르기
│   ├─ 타격
│   ├─ 걸기
│   └─ 사격
│
└─ 기술 포인트
    └─ 액티브 / 패시브 / 마스터리 강화
```

**음양 시스템은 사용하지 않는다.**

공격의 단일 / 범위 여부는 각 기술의 실제 공격 궤적과 효과에 따라 결정한다.

```text
무기
→ 사용할 수 있는 기술

기술 타입
→ 공격 방식

개별 기술
→ 위력 / 명중 / ST / 사거리 / 범위 / 효과

오행
→ 영력 속성 및 상성

수호신
→ 마법 특성

기술 포인트
→ 기술 성장
```

이를 통해 각 시스템의 역할이 중복되지 않도록 한다.
