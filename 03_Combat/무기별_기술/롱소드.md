# 롱소드 기술

[[무기별_기술]]

## 개요
베기·찌르기·타격을 모두 활용하는 균형형 무기. 레벨이 오르면 기존 기능은 유지하면서 위력·제어 성능과 ST 소모가 함께 증가한다.

### 바인드
상대 무기를 눌러 행동을 봉쇄한다. 피해는 없으며 행동 불능 지속 효과가 강해진다.
|Lv|효과|명중|ST|
|---|---|---:|---:|
|1|다음 턴 1회 행동 불능|100%|14|
|2|동일, 저항 판정 보정 +5%|101%|15|
|3|저항 판정 보정 +10%|102%|16|
|4|저항 판정 보정 +15%|103%|17|
|5|저항 판정 보정 +20%|105%|19|

## 패시브
### 빈틈 포착
상대 공격 실패 후 반격 성능 증가.
Lv.1~5 반격 피해 보정: +0% / +5% / +10% / +15% / +20%.

### 거리 대응
자신보다 리치가 긴 적을 상대할 때 방어 보너스.
Lv.1~5 방어 보너스: +3% / +5% / +7% / +9% / +12%.
