# 무기별 기술 상세 인덱스

상위 문서: [[무기별_기술]]

각 무기의 기술 구성, 기술 설명, Lv.1~Lv.5 성능 변화와 지구력(ST) 소모량을 상세하게 정의한다.

## 공통 성장 원칙

- 액티브 기술은 레벨이 오를수록 기존 기술의 핵심 성능이 점진적으로 상승한다.
- 기술 레벨 상승으로 새로운 기술 기능을 단계적으로 해금하지 않는다.
- 위력, 명중, 방어 무시, 제어 강도 등 기술의 기존 성격이 강화된다.
- 액티브 기술은 강화될수록 ST 소모량도 증가한다.
- 패시브와 마스터리는 ST를 소비하지 않는다.
- 각 표의 Lv.1은 상위 [[무기별_기술]] 문서에 정의된 기본 수치를 기준으로 한다.

## 기술 구성

모든 무기는 기본적으로 다음 구조를 사용한다.

```text
액티브 기술 5개
+
패시브 기술 2개
+
무기 마스터리 1개
=
총 8개 기술
```

마스터리는 모든 무기에서 동일한 원칙을 사용한다.

```text
무기 마스터리
→ 해당 무기 숙련도 증가
→ 해당 무기 기술 명중률 증가
```
