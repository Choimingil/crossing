# 무기별 기술

## 기본 규칙

각 무기는 총 **8개의 기술**을 가진다.

- 액티브 기술: 5개
- 패시브 기술: 2개
- 마스터리: 1개

액티브 기술은 다음 정보를 가진다.

- 기술 타입
- 기술 위력 또는 효과
- 기술 명중률
- 소모 지구력

패시브 기술은 별도의 지구력을 소비하지 않는다.

모든 기술은 **기술 포인트(TP)**를 투자하여 강화할 수 있다.

# 기술 포인트

## 기본 구조

각 기술은 기본적으로 `Lv.1 ~ Lv.5`까지 강화할 수 있다.

```text
기술 습득
↓
Lv.1
↓
Lv.2
↓
Lv.3
↓
Lv.4
↓
Lv.5
```

기술 포인트를 투자하면 다음 요소 중 하나 이상이 강화된다.

- 위력 증가
- 명중률 증가
- 소모 지구력 감소
- 사거리 증가
- 공격 범위 증가
- 부가 효과 강화
- 새로운 부가 효과 획득

## 권장 성장 방식

단순히 매 레벨마다 위력만 증가시키지 않는다.

### Lv.2

기본 성능 강화.

### Lv.3

첫 번째 특수 효과 추가 또는 기존 효과 강화.

### Lv.4

위력 / 명중 / 지구력 효율 강화.

### Lv.5

기술의 최종 특성 해금.

예:

```text
찍어당기기

Lv.1
적 1칸 당김

Lv.2
위력 증가

Lv.3
당긴 적의 방어 감소

Lv.4
소모 지구력 감소

Lv.5
적이 장애물과 충돌하면 추가 피해
```

# 마스터리

마스터리는 각 무기의 최종 성장 패시브다.

일반 기술과 마찬가지로 기술 포인트를 투자하여 강화하지만
일반 기술보다 높은 기술 포인트를 요구한다.

마스터리는 단순한 능력치 증가보다는
해당 무기의 핵심 플레이 스타일을 강화한다.

예:

## 검 마스터리

```text
Lv.1
베기 위력 +3%

Lv.2
베기 명중률 +3%

Lv.3
베기 기술 ST -1

Lv.4
베기 위력 추가 +5%

Lv.5
베기 적중 후 다음 베기 ST -2
```

## 철퇴 마스터리

```text
Lv.1
타격 방어 무시 +5%

Lv.2
타격 위력 증가

Lv.3
타격 ST -1

Lv.4
자세 붕괴 효과 강화

Lv.5
방어 중인 적에게 추가 타격 보너스
```

## 창 마스터리

```text
Lv.1
찌르기 명중 증가

Lv.2
찌르기 위력 증가

Lv.3
찌르기 ST -1

Lv.4
거리 유지 효과 강화

Lv.5
선제 견제 강화
```

| 도끼 | 고위력 공격 | 베기 + 걸기 |

# 시스템 구조

캐릭터의 전투 구성은 다음과 같다.

```text
캐릭터
│
├─ 능력치
│
├─ 오행
│   └─ 영력 속성 / 상성
│
├─ 수호신
│   └─ 마법 특성
│
├─ 주무기
│   └─ 사용 가능한 기술
│
├─ 기술 타입
│   ├─ 베기
│   ├─ 찌르기
│   ├─ 타격
│   ├─ 걸기
│   └─ 사격
│
└─ 기술 포인트
    └─ 액티브 / 패시브 / 마스터리 강화
```

기존의 **음양 시스템은 사용하지 않는다.**

공격의 단일 / 범위 여부는 캐릭터의 음양이 아니라
각 기술의 실제 공격 궤적과 효과에 따라 결정한다.

예:

```text
찌르기
→ 단일 직선 공격

횡베기
→ 좌우 범위 공격

회전베기
→ 주변 범위 공격

장거리 사격
→ 원거리 단일 공격
```

따라서 각 시스템의 역할은 다음과 같이 분리한다.

```text
무기
→ 사용할 수 있는 기술

기술 타입
→ 공격 방식

개별 기술
→ 위력 / 명중 / ST / 사거리 / 범위 / 효과

오행
→ 영력 속성 및 상성

수호신
→ 마법 특성

기술 포인트
→ 기술 성장
```

이를 통해 각 시스템의 역할이 중복되지 않도록 한다.
