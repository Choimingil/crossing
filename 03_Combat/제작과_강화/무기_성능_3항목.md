# 무기 성능 3항목

## 개요

제작과 강화로 달라지는 복잡한 재료·가공 특성은 플레이어에게 다음 세 항목으로 통합하여 표시한다.

| 항목 | 통합되는 실제 요소 | 전투 효과 |
|---|---|---|
| 균형 | 무게중심·질량 배분·손잡이 조립 상태 | 무기 기술의 소모 지구력 고정값 보정 |
| 예리함 | 공격부의 가공 상태, 날·끝의 정렬, 휨과 뒤틀림 | 무기 명중과 위력 보정 |
| 내구성 | 경도·강도·인성·잔류응력 | 파손될 때까지 유지되는 최대 내구력 |

세 항목은 캐릭터 능력치가 아니라 장비에 부여되는 제작 품질이다. 근거리 무기는 세 항목을 모두 가지지만 원거리 장비는 무기 본체와 화살통에 항목을 나누어 가진다.

| 장비 | 균형 | 예리함 | 내구성 |
|---|:---:|:---:|:---:|
| 근거리 무기 | ● | ● | ● |
| 원거리 무기 본체 | ● | - | ● |
| 화살통·화살 | - | ● | - |

- 원거리 무기의 균형과 내구성은 활 본체에 적용한다.
- 원거리 공격의 예리함은 장착한 화살통의 화살에 적용한다.
- 원거리 무기 본체에는 예리함 등급을 부여하거나 강화하지 않는다.

## 균형

균형은 무게중심, 질량 배분과 손잡이 조립 상태가 무기 운용에 얼마나 적합한지를 나타내는 품질 등급이다. 앞쪽·중앙·뒤쪽 같은 방향 유형은 사용하지 않는다.

균형이 좋은 무기는 휘두른 뒤 회수하고 다음 자세로 연결하기 쉬우므로 모든 무기 기술의 ST 소모가 감소한다. 균형이 나쁘면 궤도와 자세를 계속 보정해야 하므로 ST를 더 소비한다.

| 등급 | 무기 기술 ST 소모 | 상태 |
|---|---:|---|
| S | -2 | 질량 배분과 손잡이 조립이 매우 정교함 |
| A | -1 | 안정적으로 운용할 수 있는 우수한 균형 |
| B | 변화 없음 | 표준적인 균형 |
| C | +1 | 무게 배분이 어긋나 자세 보정이 필요함 |
| D | +2 | 운용 부담이 큰 뚜렷한 불균형 존재 |

- 보정은 액티브 무기 기술의 최종 ST 소모량에 적용한다.
- 기술 위력과 기술 레벨에 따른 ST를 계산한 뒤 균형의 고정값을 더한다.
- 기술의 최소 소모 ST는 1이다.
- 사격 기술에도 같은 균형 보정을 적용한다.

```text
최종 소모 ST
= 최대(1, 기술 소모 ST + 균형 보정)
```

## 예리함

예리함은 날이 단순히 날카로운지만 뜻하지 않는다. 공격부가 목표에 정확하게 닿고 힘을 효과적으로 전달할 수 있도록 가공된 정도를 통합한 값이다.

- 검·도끼·낫: 날의 연마 상태와 날 정렬
- 레이피어·창·폴암: 끝부분의 정렬과 직진성
- 철퇴: 타격부의 형상과 접촉면 가공 상태
- 화살통·화살: 화살촉의 연마, 직진성, 화살대와 화살촉의 축 정렬
- 공통: 좌우 질량 불균형, 칼날 뒤틀림, 휨과 축 불일치

예리함이 높으면 유효타를 만들기 쉬우며 공격부가 힘을 덜 흘리므로 명중과 위력이 함께 상승한다. 기술마다 별도의 명중 수치를 추가하지 않고 모든 해당 장비 기술의 최종 명중과 위력에 공통 적용한다.

- 근거리 기술은 무기의 예리함을 사용한다.
- 사격 기술은 원거리 무기 본체가 아니라 장착한 화살통의 예리함을 사용한다.
- 화살통을 장착하지 않았거나 사용할 수 있는 화살이 없으면 사격 기술을 사용할 수 없다.

| 등급 | 명중 보정 | 위력 보정 | 상태 |
|---|---:|---:|---|
| S | +5% | +5% | 공격부의 연마와 축 정렬이 매우 정교함 |
| A | +3% | +3% | 우수한 가공 상태 |
| B | 변화 없음 | 변화 없음 | 표준적인 완성 상태 |
| C | -3% | -3% | 미세한 불균형·마모·휨·뒤틀림 존재 |
| D | -5% | -5% | 유효타와 힘 전달을 방해하는 뚜렷한 결함 존재 |

현재 전투 규칙에서 명중은 [[능력치]]의 민첩성을 사용한다. 예리함의 명중 보정은 최종 명중 판정에 합산하며 기술마다 별도의 명중률을 두지는 않는다.

## 내구성

내구성은 열처리와 금속 조직의 결과를 하나로 통합한 등급이며, 무기가 파손될 때까지 버틸 수 있는 최대 내구력을 결정한다.

- 경도: 날과 타격부가 마모되거나 눌리는 것에 대한 저항
- 강도: 무기가 영구적으로 휘거나 변형되는 것에 대한 저항
- 인성: 충격으로 깨지거나 균열이 생기는 것에 대한 저항
- 잔류응력: 퀜칭과 냉각 후 남는 뒤틀림·균열 위험

| 등급 | 최대 내구력 | 상태 |
|---|---:|---|
| S | 30 | 열처리와 조직 상태가 매우 안정적 |
| A | 25 | 우수한 내구성과 변형 저항 |
| B | 20 | 표준적인 완성 상태 |
| C | 15 | 마모와 변형에 취약함 |
| D | 10 | 균열과 손상이 누적되기 쉬움 |

### 내구력 소모

- 현재 내구력은 최대 내구력에서 시작한다.
- 액티브 무기 기술을 한 번 사용하면 내구력이 1 감소한다.
- 다단 공격·관통·범위 공격도 기술 사용 1회당 내구력 1만 감소한다.
- 공격의 명중 여부와 관계없이 무기를 실제로 사용했으면 내구력이 감소한다.
- 패시브와 마스터리는 내구력을 소비하지 않는다.
- 영력 기술처럼 무기를 직접 사용하지 않는 기술은 내구력을 소비하지 않는다.
- 내구력이 0이 되면 무기가 파손되어 수리 전까지 장착할 수 없다.
- 내구력 1에서 사용한 기술은 피해와 부가 효과까지 정상 적용한 뒤 무기가 파손된다.

```text
현재 내구력 1
→ 무기 기술 사용
→ 현재 내구력 0
→ 무기 파손
```

수리하면 현재 내구력은 최대 내구력까지 회복한다. 수리만으로 균형·예리함·내구성 등급은 변하지 않는다.

내구성 강화를 진행하면 재열처리와 품질 검사가 끝난 뒤 현재 내구력도 변경된 최대 내구력까지 회복된다.

원거리 무기 기술을 사용하면 원거리 무기 본체의 내구력만 감소한다. 화살통은 예리함 등급만 가지며 별도의 내구력을 사용하지 않는다.

## 제작

플레이어가 재료를 전달하면 대장장이는 설계에 따라 무기를 제작한다.

```text
재료와 무기 종류 선택
→ 목표 균형 선택
→ 단조·성형·연마
→ 열처리·퀜칭·템퍼링
→ 품질 검사
→ 균형·예리함·내구성 결정
```

### 제작 결과

- 근거리 무기: 제작 시 균형·예리함·내구성 등급이 모두 결정된다.
- 원거리 무기 본체: 제작 시 균형·내구성 등급만 결정된다.
- 화살통·화살: 제작 시 예리함 등급만 결정된다.
- 균형: 질량 배분과 손잡이 조립 결과에 따라 D~S 중 하나가 결정된다.
- 예리함: 공격부의 성형·연마·축 정렬 결과에 따라 D~S 중 하나가 결정된다.
- 내구성: 재료 품질과 열처리 결과에 따라 D~S 중 하나가 결정된다.
- 좋은 재료는 높은 등급이 나올 수 있는 상한과 확률을 높인다.
- 대장장이의 숙련도와 설비는 불리한 결과의 가능성을 낮추지만 완전히 제거하지 않는다.

같은 재료와 설계도를 사용해도 완성품의 세 항목은 서로 다를 수 있다.

## 강화

강화할 때는 장비가 보유한 항목 중 하나를 목표로 선택한다.

- 근거리 무기: 균형·예리함·내구성 강화 가능
- 원거리 무기 본체: 균형·내구성만 강화 가능
- 화살통·화살: 예리함만 강화 가능

| 강화 대상 | 작업 |
|---|---|
| 균형 | 연마량·손잡이·가드·폼멜·무게 배분과 결합 상태 조정 |
| 예리함 | 근거리 공격부 또는 화살통의 화살촉 재연마, 휨·뒤틀림·축 정렬 교정 |
| 내구성 | 재가열, 퀜칭, 템퍼링과 응력 조정 |

### 강화 결과 판정

```text
강화 대상 선택
→ 재료와 현재 상태 검사
→ 재가공
→ 성공·유지·하락·손상 판정
→ 세 항목 갱신
```

가능한 결과:
- 상승: 목표한 항목의 등급이 한 단계 상승한다.
- 유지: 유의미한 변화가 발생하지 않는다.
- 하락: 목표한 항목의 등급이 한 단계 낮아진다.
- 손상: 심한 뒤틀림이나 균열이 발생해 수리 전까지 장착할 수 없다.

S등급은 더 상승하지 않으며 D등급에서 다시 하락하면 손상 상태가 될 수 있다. 강화 실패로 발생한 손상과 전투 중 내구력 0으로 발생한 파손은 모두 수리를 통해 복구할 수 있다.

## 강화의 상호 영향

강화한 항목만 항상 변하는 것은 아니다. 실제 가공 과정에서 한 특성을 개선하려다 다른 특성이 나빠질 수 있다.

- 균형 조정을 위해 금속을 과도하게 제거하면 내구성이 하락할 수 있다.
- 예리함을 높이기 위해 날을 지나치게 얇게 연마하면 내구성이 하락할 수 있다.
- 내구성을 높이기 위해 재열처리하는 과정에서 휨이나 뒤틀림이 생기면 예리함이 하락할 수 있다.

이러한 연쇄 하락은 일반 실패가 아니라 낮은 확률의 부작용으로 처리한다.

## 무기 정보 표시 예시

```text
롱소드

균형: S
예리함: A
내구성: C
현재 내구력: 15 / 15

효과:
- 무기 기술 ST 소모 -2
- 명중 +3%
- 위력 +3%
```

```text
도끼

균형: C
예리함: C
내구성: A
현재 내구력: 25 / 25

효과:
- 무기 기술 ST 소모 +1
- 명중 -3%
- 위력 -3%
```

## 원거리 장비 표시 예시

```text
장궁

균형: A
내구성: B
현재 내구력: 20 / 20

효과:
- 사격 기술 ST 소모 -1
```

```text
강철 화살통

예리함: S

효과:
- 사격 명중 +5%
- 사격 위력 +5%
```
