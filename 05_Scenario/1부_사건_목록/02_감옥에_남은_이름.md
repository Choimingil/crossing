# 제2장: 서대문형무소 — 감옥에 남은 이름

서대문형무소의 기억 공간이 현실에 겹치며 독립운동가들의 영혼과 일본인 영혼들이 반복되는 감옥에 갇힌다.

일본인 영혼을 하나로 묶지 않는다. 고문과 지배를 반복하려는 식민지 간수 악귀, 명령에 순응했던 관리의 영혼, 폭력을 증언하려는 일본인 민간인·기록자의 영혼이 서로 충돌한다.

## 전투 5회
1. 반복되는 옥사에서 독립운동가 영혼 구조
2. 기억을 지우는 간수 악귀 격파
3. 일본인 증언자 영혼을 노리는 양측 원혼 저지
4. 친일 협력자와 식민지 간수의 합성 악귀전
5. 사형장 기억 공간의 문을 열고 모든 이름 복원

주인공은 독립운동가들을 하나의 군대로 복속시키려 하지 않고 각자의 노선과 이름을 기록한다. 통일은 타인의 독립성을 빼앗는 일이 아니라는 교훈을 얻는다.
