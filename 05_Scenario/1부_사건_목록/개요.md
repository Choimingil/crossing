# 1부 사건 구성

기존 13개 핵심 챕터 사이에 **정파 성장편 4개**를 추가한다. 따라서 플레이 단위는 총 17개이며 각 단위는 기본 5전투로 구성한다. 기존 핵심 챕터 번호는 유지해 후속 문서와의 참조 충돌을 막는다.

## 주인공 정파 성장선
보호관찰 대상 → 현장 협력자 → 정식 대원 → 임시 지휘 → 사건 책임자 → 비상운영위 현장대표 → 지방 순회 특임대장 → 지부장 대행 → 정식 한국지부장 순으로 권한과 책임이 증가한다.

한국지부장 취임은 4장 보스 격파의 즉시 보상이 아니라, 4A~4D에서 조직 재건과 검증을 끝낸 결과다.
