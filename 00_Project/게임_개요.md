# 게임 개요

## 기본 정보
| 항목 | 내용 |
|---|---|
| 프로젝트명 | Crossing |
| 장르 | 스토리 중심 턴제 SRPG |
| 배경 | 현대 한국, 퇴마계와 저승 |
| 핵심 갈등 | 질서 유지 / 현실적 계약 / 경계의 부정 |

## 핵심 방향
죽은 사람의 빈 육체에서 기억을 잃은 다른 영혼이 깨어난다. 판테온 한국지부는 그를 세계의 규칙을 깬 위험 대상으로, 민간조직은 활용하거나 숭배할 기적으로, 귀신 세력은 저승에서 이탈한 영혼으로 규정한다. 주인공은 어느 진영의 정의도 그대로 받아들이지 않고 사건 속 선택을 통해 인간과 귀신의 관계를 결정한다.

## 핵심 게임 루프
사건 조사 → 진영 선택과 협상 → 출전 준비 → 전술 전투 → 단서·재료 획득 → 관계 변화 → 다음 사건

## 서사 구조
1. 프롤로그: 죽은 육체의 재가동과 최초의 저승사자 추격
2. 1부 전반: 판테온 보호관찰 아래 한국의 퇴마 사건 해결
3. 1부 중반: 민간조직의 계약술과 귀신 세력의 경계 부정에 접촉
4. 1부 후반: 세 진영의 강경파가 주인공을 둘러싸고 충돌
5. 1부 결말: 최종보스 격파 직후 저승사자에게 체포되어 저승으로 이송
6. 2부: 기존 저승 법·심판·귀환 체계를 따라 현세로 돌아갈 방법을 찾음

## 전투·능력 원칙
- 진영 단위 턴, 무기 범위, 방향과 시야, ST를 사용한다.
- 영력 1단계는 무기에 영력을 둘러 영혼을 공격한다.
- 이후 발현은 모티브 영혼이 아니라 출생 사주의 오행 속성을 따른다.
- 오행 속성은 공격의 성질과 상성만 정하며 회복·버프·디버프·유틸 능력은 제공하지 않는다.
- 캐릭터별 신화·전설 모티브 영혼 배정은 초기화 상태다.
