# 향후 스토리 고려사항

## 유라시아 원정
- 알타이 → 시베리아 → 고비사막 → 히말라야 → 이라크 바빌론 → 조지아 구간별 실제 이동 거리와 게임 내 경과 시간은 콘텐츠 확정 뒤 산정한다.
- 미니버스 아르고의 전투·이동 시스템 활용 범위를 결정한다.
- 시베리아의 설혼등, 고비의 무명 장막, 히말라야의 중음의 매듭, 바빌론 명패가 조지아 시험에서 소모품인지 영구 장비인지 확정한다.
- 각 종교와 역사 소재는 실제 신앙을 세계의 유일한 정답으로 규정하지 않고, 영혼을 해석하는 지역별 환경으로 표현한다.
- 헤라클레스 팀의 12과업 장면을 주인공 팀 사건 3~6 사이에 어떤 비율로 교차할지 조정한다.

## 대통령궁과 수장전
- 세 시험의 난이도와 앞선 지역 아이템의 사용 비중을 확정한다.
- 바빌론 명패로 발견하는 성물 계약 조항과 조지아 정부의 제소 근거를 세부화한다.
- 두 원정의 증거가 합쳐지는 순서와 계승전 판정 기준을 구체화한다.

## 기억과 증언
- 저승에서 만나는 과거 원정대원·희생자·재판 관계자의 명단을 확정한다.
- 같은 사건에 대한 상반된 증언과 이를 검증할 물증을 사건별로 배치한다.
- 메데이아의 증언이 진실인 부분과 조작된 부분을 구분한다.
- 윤태경은 저승 진입이나 사망만으로 기억을 회복하지 않는다는 원칙을 유지한다.

## 케이론 이후와 최종 정치
- 환생한 케이론에게 과거 기억을 강제로 주입하지 않는다.
- 이아손이 제우스 직책을 거부할지 임시로 맡고 분권할지 결정한다.
- 메데이아와 아카스토스 패배 이후의 심판 방식을 확정한다.
