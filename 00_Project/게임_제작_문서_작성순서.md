# 게임 제작 문서 권장 작성 순서

> 실제 게임 제작에 필요한 기획 문서를 하나씩 완성하기 위한 임시 진행 관리 문서다.
> 각 항목이 확정되면 상태를 갱신하고 관련 문서를 연결한다.

## 상태 기준

- **작성 전**: 아직 별도 문서가 없음
- **작성 중**: 초안이 있으며 세부 규칙 또는 수치 검증이 필요함
- **1차 완료**: 프로토타입 제작에 필요한 기준이 정리됨
- **확정**: 구현 및 테스트 결과까지 반영됨

## 현재 확정된 방향

### 게임 개요

- 플랫폼: 모바일 웹 및 모바일 앱
- 화면 방향: 가로
- 목표 플레이 시간: 약 12시간
- 장르: 스토리 중심 턴제 SRPG

### 전투 및 성장

- 기술 위력과 전투 계산식은 최초 프로토타입용 초안 수치를 사용한다.
- 모든 무기 기술과 영력 기술은 ST를 소비한다.
- Lv.1 기본 능력치는 모두 5이며 최대 HP는 정신력, 최대 ST는 지구력으로 계산한다.
- 일반 무기 기술은 최대 4개 장착하며 영력 각성 기술은 별도 슬롯을 사용한다.
- 진영 단위로 라운드를 진행한다.
- 출전한 아군팀과 적팀의 평균 민첩성을 비교해 첫 선공팀을 정한다.
- 레벨업마다 능력치 포인트 3과 기술 포인트 1을 얻는다.
- 모든 기술과 무기 마스터리의 최대 레벨은 10이다.

### 경제

- 주요 보상은 돈이다.
- 일반 제작 재료는 온라인 쇼핑몰에서 구매한다.
- 제작, 강화, 수리는 판테온 내 대장장이에게 돈을 지불해 진행한다.
- 성물과 영력 재료 등 특수 재료는 사건 보상으로 획득할 수 있다.

### 콘텐츠와 진행

- 적 역할은 각 시나리오에 맞춰 정한다.
- 보스는 공통 3페이즈 패턴 초안을 사용한 뒤 사건별로 변형한다.
- 프롤로그 전투는 20×20 사각 타일 맵을 기준으로 한다.
- 시야는 방향과 무관한 캐릭터 중심 5칸이며 엄폐물은 시야를 차단한다.
- 최대 레벨은 50이며 비출전 캐릭터는 경험치를 얻지 않는다.
- 스토리 반복 전투 대신 별도 사냥터를 사용한다.
- 기본 흐름은 정비 → 전투 전 컷신 → 전투 → 전투 후 컷신 → 정비다.

### 기술 및 표현

- 2D 도트 그래픽을 사용한다.
- 진행 상황은 자동 저장한다.
- 웹과 앱은 동일한 게임 규칙과 데이터를 공유한다.

## 관리 원칙

1. 위 순서대로 문서를 검토하고 하나씩 1차 완료 상태로 올린다.
2. 새 문서를 작성할 때 기존 세계관·전투·캐릭터·시나리오 문서와 충돌하는지 확인한다.
3. 수치가 확정되지 않은 내용은 **가안** 또는 **미정**으로 표시한다.
4. 프로토타입 구현에 필요한 수준까지 작성되면 **1차 완료**로 변경한다.
5. 실제 플레이 테스트 후 조정된 내용까지 반영되면 **확정**으로 변경한다.
