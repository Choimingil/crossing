# 인간과 저승

## 영혼의 순환 규칙
1. 인간이 죽으면 영혼이 된다.
2. 영혼이 죽으면 인간으로 환생한다.
3. 인간으로 환생할 때 이전 기억을 잃는다.
4. 다시 영혼 상태가 되면 인간이었을 때와 영혼이었을 때의 모든 기억이 돌아온다.

## 저승 사회
저승에는 현세와 같은 사회가 있다. 인간 영혼들이 만든 사회이므로 선악과 법의 기준도 현세의 도덕 변화에 따라 바뀐다.

| 기능 | 기관과 역할 |
|---|---|
| 행정부 | 저승의 왕이 저승을 통치 |
| 사법부 | 영혼의 무게를 재어 죄를 판단 |
| 입법부 | 최고신 12명(11명과 저승의 왕)이 현세·저승의 규칙을 선언 |
| 국회 | 극락·천국·올림포스 |
| 경찰 | 저승사자. 경찰청장은 헤르메스 |

## 올림포스의 직책
| 직책명 | 담당 |
|---|---|
| 제우스 | 입법부의 왕, 세상의 왕 |
| 아테나 | 순수 학문과 지식 |
| 헤파이스토스 | 공학 |
| 아레스 | 국방 |
| 아프로디테 | 연예 |
| 헤라 | 가족 |
| 데메테르 | 농업 |
| 포세이돈 | 수산 |
| 아폴론 | 보건·복지 |
| 아르테미스 | 환경 |
| 헤르메스 | 저승 경찰 |
| 저승의 왕 | 행정부 및 최고신 회의의 한 자리 |

모든 지식은 과학적 탐구에서 기인하며, 아테나는 순수 학문의 제도적 상징이다.

## 헤스티아
헤스티아는 올림포스의 불을 지키는 직책이다. 표면상 권력이 없어 지금까지 한 번도 교체되지 않았다. 그러나 제도의 연속성과 의식의 승인권을 이용해 장기간 비선 권력을 형성했다. 극보수 성향으로 현 체제의 변화를 막으려 한다.
