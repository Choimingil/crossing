# 인공 신격화

## 원리
세계의 에너지 법칙을 인위적으로 반복한다.

```text
괴담 생산 → 집단 공포 → 공포 에너지 집중 → 인공 귀
영웅 서사 조작 → 집단 추앙 → 숭배 에너지 집중 → 인공 신격
```

## 과정
1. 마을·학교·온라인 공간에 특정 괴담이나 영웅담을 퍼뜨린다.
2. 공포 또는 숭배의 대상을 하나의 영혼이나 인간에게 고정한다.
3. 반복 의식과 매체로 감정을 증폭한다.
4. 귀신·신의 영력을 강탈해 대상에게 주입한다.
5. 여러 영혼을 한 육체에 넣어 필요한 기억과 능력을 조합한다.
6. 불안정한 인공 귀 또는 인공 신을 완성한다.

## 위험
- 육체의 원래 인격이 여러 영혼에 침식된다.
- 공포와 추앙이 끊기면 신격이 붕괴한다.
- 감정 공급을 유지하기 위해 마교가 지속적으로 사건과 희생자를 만든다.
- 신격화된 인간은 사람들의 기대에 갇혀 자율성을 잃는다.
