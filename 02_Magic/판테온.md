# 판테온

판테온은 모든 종교와 신화 속 신들의 공통 역할을 추출해 통합적으로 숭배하는 퇴마 계통이다. 하나의 신에게 영구 귀속되기보다 사건에 필요한 신과 직책을 선택해 의식을 올린다.

## 운용 원칙
1. 사건의 성격과 필요한 권능을 분석한다.
2. 문화권을 넘어 같은 역할을 가진 신들의 공통점을 찾는다.
3. 가장 적합한 신에게 제한적으로 숭배와 영력을 집중한다.
4. 계약이 교단의 독점이나 맹목적 복종으로 변하지 않도록 기록한다.

스승 퇴마사는 이 계통의 최상위 실전가이며, 여러 신앙 체계를 AI처럼 분석·조합한다. 자세한 인물 설정은 [[스승_퇴마사]] 참고.
