# 영력 3단계

## 개요
Lv.30에 무기 표면을 넘어 오행 영력을 외부로 대규모 발산해 영혼을 직접 공격한다.

- 선행 조건: [[영력_2단계]]
- 사용 시점 최대 ST의 60% 소비
- 장착 무기 없이도 사용 가능
- 무기 위력·내구·마스터리 보정은 적용하지 않음
- 기술 차이는 피해 계수, 사거리, 범위, 관통, 타격 수로만 구성

## 속성 형상
목·화·토·금·수의 형상은 [[사주_오행_속성]]을 따른다. 3단계 기술은 모티브 영혼, 전생, 신화적 전승으로 정하지 않는다. 모든 캐릭터의 개별 3단계 기술은 사주와 전투 설계가 확정될 때 새로 작성한다.

회복, 부활, 보호, 강화 제거, 상태이상 같은 부가 기능은 3단계 기술에서 사용하지 않는다.
