# 문화권별 속성 계승

## 원칙
영력의 속성은 하나의 보편 분류로 고정되지 않는다. 인간은 자신이 속한 문화가 자연과 영혼을 해석하는 방식을 통해 영력에 형태를 부여한다.

```text
순수 영력
→ 문화권의 자연관
→ 스승·문파·의식의 계승
→ 개인의 속성
```

## 동아시아: 사주팔자와 오행
생년월일시의 사주팔자와 영력 각성 의식을 결합해 목·화·토·금·수의 주속성과 보조속성을 판정한다.

## 서양: 4원소설
불·공기·물·흙 가운데 개인의 기질과 입문 의식에 공명하는 원소를 주속성으로 삼는다.

| 원소 | 무기 피막의 공격 표현 |
|---|---|
| 불 | 열·폭발·확산 |
| 공기 | 속도·압력·궤도 변화 |
| 물 | 흐름·파동·연속 타격 |
| 흙 | 질량·충격·관통 |

## 계승의 기준
- 출생지보다 실제로 수련한 계승 체계가 우선한다.
- 부모 문화와 성장 문화가 다르면 본인이 입문한 계보를 따른다.
- 여러 체계를 배워도 영혼에 처음 안정된 주계승 하나가 기준이 된다.
- 복수 계승은 가능하지만 속성 충돌과 피막 붕괴 위험이 크다.
- 같은 자연현상도 문화권에 따라 별개의 속성으로 해석될 수 있다.

## 게임 규칙
서로 다른 속성 체계는 우열 관계가 아니다. 각 체계 안의 상성과 전투 표현만 다르며 피해 기준은 동일한 범위에서 조정한다.
