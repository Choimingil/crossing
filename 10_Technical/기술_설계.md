# 기술 설계

## 기술 스택 초안

| 영역 | 선택 |
|---|---|
| 언어 | TypeScript |
| 전투 화면 | Phaser 3 |
| 정비·상점·대화 UI | React |
| 빌드 | Vite |
| 모바일 앱 패키징 | Capacitor |
| 로컬 저장 | IndexedDB |
| 상태 관리 | Zustand 또는 동급 경량 상태 관리 |
| 테스트 | Vitest, Playwright |
| 그래픽 | 2D 도트 |
| 화면 | 가로형 |

Phaser는 타일맵·스프라이트·카메라·입력과 전투 연출을 담당하고 React는 정비, 기술, 쇼핑, 대장간과 설정 화면을 담당한다. 웹 빌드를 Capacitor로 감싸 Android·iOS 앱을 만든다.

## 플랫폼 초안

- 모바일 웹: 최신 Chrome, Safari의 최근 두 개 주요 버전
- Android 앱: Android 10 이상
- iOS 앱: iOS 16 이상
- 화면 비율: 16:9 기준, 19.5:9까지 안전 영역 대응
- 세로 진입: 게임을 중단하지 않고 가로 회전 안내 오버레이 표시
- 네트워크: 기본 게임은 오프라인 가능
- 계정·클라우드 저장: 최초 버전 제외, 후속 기능으로 검토

## 렌더링

- 기준 내부 해상도: 1920×1080
- 타일: 48×48 px
- 프롤로그 맵: 20×20
- 캐릭터·무기 스프라이트 분리
- 최근접 보간으로 픽셀 선명도 유지
- 목표 60fps, 저사양 기기 30fps 안정 유지
- 전투 판정은 렌더링 프레임과 분리한다.

세부 아트 규격은 [[2D_도트_아트_가이드]]를 따른다.

## 데이터 분리

다음 데이터는 코드와 분리된 JSON 또는 TypeScript 데이터 파일로 관리한다.

- 캐릭터 기본 능력치와 투자값
- 무기 위력·요구 근력·이동력 감소
- 기술 Lv.1~10 수치와 장착 슬롯
- 적 레벨·역할·AI·보스 페이즈
- 맵 좌표·엄폐물·초기 배치
- 대사·초상화·컷신 명령
- 쇼핑몰 가격·제작·강화·수리
- 경험치와 사냥터

## 자동 저장

자동 저장 슬롯은 정상 저장 1개와 직전 백업 1개를 사용한다.

저장 시점:

1. 정비에서 출전을 확정할 때
2. 전투 시작 직전
3. 각 진영 턴 시작
4. 전투 승리와 보상 확정
5. 능력치·기술 포인트 배분
6. 구매·제작·강화·수리 완료
7. 컷신 종료와 다음 단계 진입

저장 중 종료되면 직전 정상 저장을 복구한다. 전투 중 앱 종료 시 최근 진영 턴 시작 상태로 돌아간다.

## 저장 데이터

- saveVersion
- gameVersion
- 현재 사건과 컷신 위치
- 캐릭터 레벨·경험치·능력치
- 습득 기술과 장착 기술 4개
- 장비·재료·돈
- 전투 임시 상태
- 설정과 접근성 옵션

마이그레이션 함수로 이전 saveVersion을 최신 구조로 변환한다.

## 터치 입력

- 최소 터치 영역 44×44 CSS 픽셀
- 첫 탭은 미리보기, 확인 탭은 확정
- 핀치 확대와 두 손가락 이동 지원
- 이동 확정 뒤에는 취소할 수 없음을 시각적으로 표시
- 브라우저 뒤로가기와 앱 백버튼은 게임 내 확인창으로 처리
