# 2D 도트 아트 가이드

## 방향

현대 한국의 도시·폐건물·종교 시설과 신화적 영력을 결합한 어두운 2D 도트 그래픽을 사용한다. 공포 분위기는 유지하되 전투 유닛과 타일 판독성을 우선한다.

## 기준 규격 초안

| 자산 | 기준 |
|---|---|
| 전장 타일 | 48×48 px |
| 캐릭터 본체 | 48×64 px |
| 무기 스프라이트 | 최대 64×64 px, 본체와 분리 |
| 얼굴 초상화 | 256×256 px |
| 상태 아이콘 | 32×32 px |
| 기술 아이콘 | 48×48 px |
| 영력 이펙트 | 96×96 px 이내 기본, 고유기 예외 |
| 기준 화면 | 1920×1080, 16:9 가로 |

모바일에서는 내부 기준 해상도를 유지하고 화면 크기에 맞춰 정수 또는 최근접 보간으로 확대·축소한다.

## 캐릭터와 무기 분리

캐릭터 본체와 무기를 별도 레이어로 제작한다.

~~~text
캐릭터 본체
+ 방향별 손 위치 앵커
+ 주무기 스프라이트
+ 보조무기 스프라이트
+ 영력 이펙트
~~~

- 무기 교체 시 캐릭터 본체를 다시 그리지 않는다.
- 무기별 손 위치, 각도, 앞뒤 레이어 값을 데이터로 관리한다.
- 양손 무기는 두 손 앵커를 사용한다.
- 방패는 방향에 따라 본체 앞·뒤 레이어가 바뀐다.

## 방향과 애니메이션

상·하·좌·우 네 방향을 기본으로 한다.

| 상태 | 프레임 |
|---|---:|
| 대기 | 방향당 4 |
| 이동 | 방향당 6 |
| 피격 | 방향당 2 |
| 전투불능 | 방향당 4 |
| 휘두르기 | 방향당 6 |
| 뻗기 | 방향당 5 |
| 사격 | 방향당 6 |
| 영력 시전 | 방향당 6 |

좌우 반전은 비대칭 장비와 보조무기 때문에 최종본에서 별도 확인한다.

## 초상화

- 주요 인물과 이름 있는 사건 인물은 초상화를 사용한다.
- 기본 표정: 중립, 긴장, 분노, 슬픔, 미소
- 보스는 전투 상태 변화용 표정 1개를 추가한다.
- 일반 적과 군중 NPC는 공용 초상화를 사용할 수 있다.

## 팔레트

- 배경: 네이비, 콘크리트 회색, 저채도 녹색
- 아군 영력: 청록·청색
- 적대 영력: 자홍·적색
- 성물: 금색·백색
- 판테온 실내: 따뜻한 황색 조명
- 저승: 검정·보라·회청색

## 콘셉트 이미지 기준

초기 콘셉트 시안은 다음 요소를 검증한다.

- 모바일 가로 화면에서 전장 우선 배치
- 폐병원과 현대 도시의 야간 분위기
- 검·창·활 사용자의 실루엣 구분
- 캐릭터와 무기의 분리 가능성
- 엄폐물과 시야 차단 구조
- 초상화와 최소 전투 UI의 조화

콘셉트 이미지는 최종 UI나 실제 스프라이트 시트가 아니며 제작 규격 검증 후 타일과 캐릭터를 개별 자산으로 다시 제작한다.
