# 적과 AI

## 적 역할 결정 원칙

적 역할은 고정된 직업표보다 각 시나리오의 사건 원인과 영혼의 성질에 맞춰 정한다. 다만 AI와 밸런스 관리를 위해 다음 전투 역할을 공통 태그로 사용한다.

| 역할 | 행동 성향 |
|---|---|
| 돌격형 | 가까운 아군에게 접근해 단일 공격 |
| 방어형 | 길목과 목표물을 지키며 반격 유도 |
| 사격형 | 거리를 유지하고 가장 가까운 공격 가능 대상 사격 |
| 교란형 | 넘어짐, 이동 제한, 능력치 감소 사용 |
| 지원형 | 아군 적에게 버프·회복 제공 |
| 소환형 | 조건에 따라 증원 생성 |
| 보스형 | 고유 패턴과 페이즈 보유 |

한 적이 최대 두 개의 역할 태그를 가질 수 있다.

## 선공

- 출전한 모든 아군의 현재 민첩성 합계와 초기 배치된 모든 적의 현재 민첩성 합계를 비교한다.
- 민첩성 총합이 더 높은 팀이 첫 라운드에 선공한다.
- 동률이면 아군이 선공한다.
- 이후 진영 단위로 교대한다.
- 증원은 선공 계산에 포함하지 않는다.

## 공통 AI 우선순위

1. 이번 행동으로 승리·패배 조건을 직접 달성하거나 저지할 수 있는가
2. 현재 위치에서 전투불능으로 만들 수 있는 대상이 있는가
3. 위험한 아군의 영력 기술 또는 범위 공격을 방해할 수 있는가
4. 역할에 맞는 기술을 가장 효과적으로 사용할 수 있는가
5. 공격 가능한 가장 가까운 대상으로 이동하는가

동일 우선순위라면 낮은 HP, 가까운 거리, 낮은 방어 순으로 대상을 선택한다. AI는 플레이어에게 보이지 않는 정보를 사용하지 않는다.

## 난이도 가안

| 난이도 | AI 차이 |
|---|---|
| 쉬움 | 집중 공격과 측후방 이동 빈도 감소 |
| 보통 | 공통 우선순위 사용 |
| 어려움 | 집중 공격, 측후방, 제어 연계 적극 사용 |

단순 능력치 증가보다 행동 판단의 차이를 우선한다.

## 보스 공통 패턴 초안

### 1페이즈: 관찰

- 기본 공격과 대표 기술을 사용한다.
- 플레이어가 보스의 범위와 기믹을 익히는 구간이다.

### 2페이즈: 전장 변화

- HP 60% 이하에서 진입한다.
- 증원, 위험 지역, 시야 방해 또는 위치 이동 중 시나리오에 맞는 하나의 기믹을 사용한다.

### 3페이즈: 최후 행동

- HP 25% 이하에서 진입한다.
- 강한 기술을 예고한 뒤 다음 보스 진영 턴에 사용한다.
- 플레이어는 이동, 제어, 방어 또는 집중 공격으로 대응할 수 있어야 한다.

## 보스 제어 저항

보스에게 행동 불가 상태를 그대로 적용하지 않는다. 넘어짐 등은 반격 불가와 능력치 감소만 적용하고 행동은 유지한다. 위치 이동 효과는 한 칸으로 제한하거나 면역 처리한다.
