# 작품 레퍼런스

## 베르세르크

주요 참고 요소:
- 인간과 초월적 존재의 대립
- 운명에 대한 저항
- 초월적 존재가 인간 사회에 개입하는 구조
- 인간의 욕망과 초자연적 힘의 관계

## 차별화해야 할 핵심

### 신과 귀의 분류

```text
추앙 / 공포
×
도움 / 해악
```

을 통해
- 선신
- 악신
- 선귀
- 악귀

를 구분한다.

### 인간과 신의 순환

```text
인간
→ 저승 존재
→ 죽음
→ 환생
→ 인간
```

### 인간이 신의 힘의 원천

> 신이 인간을 만든 것이 아니라 인간이 신을 만든다.
