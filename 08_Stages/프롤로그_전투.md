# 프롤로그 전투

## 목적

최초 프로토타입과 실제 게임의 튜토리얼 기준이 되는 전투다. 주인공이 낯선 육체에서 깨어난 직후 영혼에게 습격받고 판테온 인물에게 구조되는 상황을 다룬다.

## 맵 규격

| 항목 | 내용 |
|---|---|
| 크기 | 20 × 20 타일 |
| 방식 | 사각 타일, 4방향 |
| 배경 | 야간의 폐쇄된 도시 공간 가안 |
| 기본 승리 조건 | 모든 적 처치 |
| 기본 패배 조건 | 주인공 전투불능 |
| 목표 플레이 시간 | 10~15분 |

## 공간 구성 가안

- 시작 구역: 주인공과 약한 적을 배치해 이동과 기본 공격을 학습한다.
- 중앙 구역: 벽과 장애물로 시야와 방향을 학습한다.
- 구조 구역: 판테온 아군이 합류하고 무기 기술을 사용한다.
- 종료 구역: 교란형 적을 포함한 소규모 최종 교전이 발생한다.

20×20 전체를 항상 사용하기보다 장애물과 폐쇄 구역으로 실제 이동 영역을 제한한다.

## 출전 구성

### 아군

- 주인공
- 스승 퇴마사 또는 연습생
- 구조 장면에서 합류하는 판테온 인물 1명

### 적

- 돌격형 영혼
- 사격 또는 원거리 현상형 영혼
- 교란형 지박령

최초 구현은 총 3종을 사용하고 보스는 배치하지 않는다.

## 튜토리얼 순서

1. 이동
2. 방향과 시야
3. 기본 공격
4. 진영 턴 종료
5. 무기 기술과 ST
6. 아군 합류
7. 측면·후방과 반격
8. 승리 조건

영력 2단계와 3단계, 제작, 강화, 복잡한 상태이상은 프롤로그 전투에서 설명하지 않는다.

## 보상

- 사건 진행에 필요한 단서
- 초기 자금
- 온라인 쇼핑몰과 판테온 정비 기능의 단계적 해금
- 전투 결과 경험치

구체적인 적 수, 좌표, 장애물 배치는 [[전투_계산식]] 테스트 후 확정한다.
